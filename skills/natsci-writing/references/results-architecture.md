# Results as a discovery narrative

Version 1.0; added in NatSci-Writing-skills 1.2.8.2 (2026-11-27).

A scientific Results section answers a sequence of questions. It is not a pipeline report and not an inventory of algorithms, parameters or software. Each subsection should let a reader who has not seen the Methods understand what was asked, what was observed and what the observation means.

## Six moves

1. Existence: show that the phenomenon occurs. Open with one concrete example and state what it demonstrates; then quantify how general it is.
2. Mechanism: change one causal ingredient and show that the path and the outcome change. Distinguish the path from the endpoint.
3. Diversity: add the process that creates variation (for example cleavage and ligation in an open pool) and show how it changes the products.
4. Coverage: separate what is already known from what is unassigned. Report both; do not treat a database match as the only successful outcome.
5. Origin: state whether the phenomenon requires a template or target. Show the controls that exclude composition, predictor memory and background.
6. Boundary: use a case series to test whether the effect extends to stability, function or a longer process. Report the window and the failure mode.

## Paragraph contract

Each Results subsection should contain five functions, in this order:

- Question: one sentence that names the scientific question.
- Design: one or two sentences on what was varied or measured.
- Observation: the direct result, with one concrete example and the quantitative summary.
- Interpretation: what the observation means mechanistically; what alternative it excludes.
- Boundary: what the result does not establish.

Do not begin with software, file formats, parameter grids or a list of analyses. Methods belong in Methods; Results report findings.

## Language

- Prefer "we asked whether", "we found that", "this shows that" to "we then ran", "the pipeline produced" or "the workflow consisted of".
- A Results heading and a figure legend title must be complete scientific statements or noun phrases, 40-60 characters, not compressed slogans. Completeness takes priority over brevity.
- Each section must end with an interpretation, not with a description of the analysis.
- A negative or bounded result is a result: report the over-extension case and the stability window instead of hiding them.

## Audit

List the six sections. For each, mark question, design, observation, interpretation and boundary. A section without a question or without an interpretation fails. Then check that the first section contains a concrete example and that the last section contains a case-level calculation and a boundary.
