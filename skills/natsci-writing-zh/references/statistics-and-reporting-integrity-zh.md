# 统计、报告与研究诚信

版本 1.1.0；更新日期 2026-11-23。起草统计方法、审查结果与图注、回复统计审稿意见、准备 Nature Portfolio reporting summary 时阅读。本文件是报告与审查指南，不替代统计学家对原始数据的再分析。

## 一、先讲设计，再讲统计语言

区分三个问题：测量了什么、分析单位是什么、断言了什么推断。

每项分析明确：终点/响应与组别/条件；独立实验单位；生物学与技术重复；重复测量、配对、区组、批次、供者、动物、患者、样地、模型运行；纳入/排除与缺失处理；随机化与盲法（适用时）；变换/归一化；检验或模型、假设、校正族；估计量、不确定性、精确 P、样本量；软件/包/版本。

默认以独立实验单位为 n。不得把细胞、视野、光谱、reads、孔、重复读数、模型运行或技术重复默认为独立生物学样本。

## 二、Nature 统计要求（正刊）

首次投稿时统计信息必须足以让编辑与审稿人评估。方法必须写：每个检验及其对应比较/模型；单双侧；独立实验单位；生物/技术重复定义；配对/非配对或重复测量结构；纳入/排除、随机化、盲法（适用时）；多重比较校正策略。

数字报告必须写：精确 n（n 变化时逐一报告）；每个误差棒/区间定义；重复实验次数；显著与非显著结果的精确 P（相关时）；ANOVA 的 F 与自由度；t 检验的 t 与自由度；结果附近的确切比较、检验族与尾向。

生命科学、行为/社会科学、生态/演化/环境科学及部分物理科学需要 Reporting Summary；把完成表与方法、结果、图注和源数据交叉核对，标出样本量、排除、随机化、盲法或软件矛盾。

## 三、统计方法段

顺序：软件/环境 → 数据汇总约定 → 样本量与重复定义 → 检验/模型选择 → 多重性策略 → 阈值与精确报告 → 排除与稳健性。

优先精确值：
- "与对照相比，处理 A 与更高响应相关（均差……，95% CI……，P =……）。"
- "分析以动物为独立单位；细胞水平测量用于展示个体内变异。"
- "证据与增加一致，但小样本限制了精度。"

避免：仅凭 P 值写 proved/demonstrated conclusively/confirmed the mechanism；没有效应量或不确定性的 highly significant；实验只有三只动物/三个培养时写 n = 300 cells；只写 ns；小样本无依据地写 data were normally distributed。

## 四、常见失败模式

**P0——可能动摇核心断言**：伪重复（n 写细胞/图/视野，独立单位却是动物/患者/培养/批次/实验）；未校正多重比较且检验族未定义或选择性报告；错误交互推断（一个比较显著、另一个不显著就称两效应不同）；分析单位错配（配对、匹配、区组、纵向、嵌套或重复测量却按独立分析）。

**P1——重要报告风险**：只讲显著性、无效应量/区间；小样本过度断言；正态性/等方差假设无依据；缺软件/版本、精确 n 或误差棒定义；星号无校正状态或精确 P。

**P2——清晰度**：重复术语不一致；图注缺 panel 特异 n；ns 标签不清；统计散落在方法、图注和 SI 而无索引。

## 五、图件统计

每个定量 panel 图注应写：点/柱/箱/线/阴影代表什么；精确 n 及 n 计数对象；汇总约定（mean ± s.d./s.e.m.、median+IQR、95% CI、模型估计）；检验/模型、配对或重复测量；多重比较校正；精确 P 或星号阈值；源数据是否含原始独立值。

图型规则：柱图优先叠加个体点，保留柱时定义误差与 n；箱线图写中位数、箱界、须规则、离群规则、n；小提琴图写点含义、密度注意事项、独立单位，不得让密集细胞级小提琴看起来像很多独立实验；时间序列写是否同一单位随访，推断使用全部时间点时用重复测量/混合模型；热图/组学写归一化、标准化、聚类距离/连接、多重检验/FDR、行列是否事后选择；回归/相关写系数或相关系数、不确定性、n、点独立性和描述/推断性质。

星号应写检验、校正和比较族；精确 P 和样本量放 Source Data。

## 六、图像诚信

显微、凝胶、印迹和处理图像记录：原始文件与处理文件；裁剪；亮度/对比度/gamma 及全局或局部；伪彩；比例尺校准与长度；拼接、泳道重排、它图复用；定量链接；处理软件。

全局调整通常比局部选择性编辑安全。若调整改变相关背景或条带可见性，应标出而不是静默归一化。

## 七、数据、代码与材料报告

- 数据可用性：每个数据集映射到仓库、登录号/DOI 或确切源数据文件；写限制与获取途径；正式引用已存缴数据集。
- 代码可用性：核心自定义代码单独标题陈述；仓库/DOI、版本、许可证、环境、入口；核心代码需给审稿人访问。
- 材料：关键抗体、细胞系、模式生物的持久标识（RRID）；来源、认证、分发限制；方案存缴并引用。
- 不编造仓库名、DOI、登录号、许可证、软件版本、批件或审稿人身份。

## 八、严重度与审稿风险措辞

按第四节 P0/P1/P2。中性措辞："审稿人可能质疑分析是否把正确的独立单位作为 n"；"图注未说明点是生物学重复还是技术子样本"；"断言强于当前报告的统计证据"；"比较族未定义，校正状态不清"。

未提供原始数据和完整设计时，优先写"无法从现有材料评估""潜在风险""需要作者确认"。

## 十、报告诚信终检

- 每个核心断言的独立单位是否定义？
- 生物学与技术重复是否分开？
- 每个核心结果是否映射到检验/模型或清晰描述性陈述？
- 多重性是否校正或明确限定/预设？
- 精确 n、误差定义、P 值与检验统计量是否可得？
- 图件统计是否与方法、源数据一致？
- 图像调整与原始文件溯源是否记录？
- 数据/代码/材料声明是否真实、持久、与稿件一致？
- Reporting Summary 是否完整且一致？
- 缺失事实是否标注而非编造？

## 十一、数据、代码与材料：强制存缴与获取

Nature 正刊及多数 Nature Portfolio 期刊：

- 每篇原创研究需要独立标题的 Data Availability；按当期结构放在方法/方法末尾。
- 把自产与复用数据集映射到仓库、登录号或确切源数据/补充文件；在参考文献中引用存缴数据集。
- 序列、结构/EM 图、基因表达、蛋白组、晶体学及领域数据使用社区仓库；个人网站、可变云盘、未归档 GitHub 分支不是持久记录。
- 核心代码需独立 Code Availability、审稿人访问、带版本 DOI 的归档与许可证；限制写清楚。
- 材料：关键抗体、细胞系、模式生物用持久标识（RRID）；来源、认证、分发限制；方案存缴并引用 DOI。
- 受控、临床或第三方数据：写限制原因、负责委员会/途径、资格、申请流程、预计时限、数据使用协议、可公开元数据。"未决定"不是共享方案。
- 投稿前检查强制存缴门与结构验证文件；核实登录号可解析。

报告指南：按研究类型使用相应标准（随机试验 CONSORT、观察性研究 STROBE、系统综述 PRISMA、动物研究 ARRIVE、领域标准）。Reporting Summary 必须与方法、结果、图注、源数据一致。

**数据诚信审计**：每个关键数据集有持久途径；每个登录号可解析；无缺少原因/途径/资格/元数据的"可索取"；审稿人可运行代码；材料申请有明确途径；声明跨文件一致。
