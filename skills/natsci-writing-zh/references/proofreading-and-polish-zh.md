# 校对与句子润色

版本 1.2.1；更新日期 2026-11-23。最终语言检查、非母语英文润色、返修后清理或投稿前系统校对时阅读。配合 language-and-taste-zh.md 与 writing-diagnostics-zh.md。

## 一、五轮扫描

按顺序完成，一轮做完再做下一轮。

1. **拼写与术语**：拼写、技术术语、大小写、连字符变体、重复词、空格、基因/蛋白/物种名、单位符号、希腊字母。
2. **语法**：主谓一致、时态、冠词、介词、代词指代、残缺句、流水句、逗号粘连、悬垂修饰、平行结构。
3. **不当用词**：口语、缩写形式、模糊量词（very/quite/a lot of）、多余限定、情绪化/主观语言、拟人化、无依据评价形容词、AI 腔标记。
4. **别扭表达**：过复杂句、该主动却被动、冗词、重复、指代不清、非地道表达、名词链、修饰语堆叠、过长插入语。
5. **学术风格与一致性**：术语跨节一致、缩写只定义一次、时态、引用风格、公式/单位符号、数字格式、图表引用、标题风格、英美拼写、参考文献与图注一致。

## 二、句子级规则

- 作者动作优先主动语态；对象是重点时用被动。
- 本文已确立的断言与模型行为用现在时；已做实验与前任工作用过去时。
- 缩写首次定义，之后用短形式，不在每节重复定义。
- 不用连字符连接独立分句；复合修饰语可以。
- 删减：in order to → to；due to the fact that → because；at this point in time → now；make use of → use。
- 一句一个命题；从句依附主句。
- 名词化改动词："X 被 Y 激活导致……" → "Y 激活 X，进而……"。
- 保留技术术语、基因/蛋白命名与 LaTeX/标记；不"纠正"领域行话。
- 不过度修改正确但不常见的表达；保留作者声音与论证。

## 三、概念落地与节奏

读者只能跟上已经"落地"的概念。段落使用某术语/想法前，要么读者已知，要么前文已引入；若先出现后解释，补定义或后移。

段落节奏：一段一个动作；主题句给断言或问题；中间证据与解释；结尾给推论或引出下段；句长交替，避免连续三个长句，也避免一串短句像清单。

## 四、去 AI 腔

警惕：模板连接（Moreover/Furthermore/Additionally/Notably/Importantly）、三项排比、"不仅……而且……""在一定意义上""发挥关键作用""奠定基础""开辟新方向""深入探讨"、空洞的"鲁棒/全面/强大"、只是重复段落的总结句。换成具体关系、比较、数字或后果。按 writing-diagnostics-zh.md 词表统计。

## 五、数字、单位与引用

- 每个数字复算或核实；摘要、结果、图注、补充材料一致。
- 数值与单位间留空格；符号统一；必要时用 SI。
- 统计符号斜体/格式一致；P 值按期刊格式。
- 图表引用一致（Fig. 1a、Extended Data Fig. 2、Supplementary Table 1）。
- 参考文献编号/顺序、作者格式、DOI、题名、期刊缩写；无断链域代码。
- 公式变量定义、单位保留、上下标渲染正确。

## 六、输出约定

校对任务返回：五轮摘要（各类问题数与修复数）；问题日志（位置、原文、修改、理由、严重度）；完整修订文本；需作者核实的问题（数字、术语、引文）；若文本已足够好，明确写"无需实质修改"，不制造吹毛求疵的改动。

修订任务保留未改段落、标记改动、保留作者声音；不静默重写论证。

## 七、校对终检

- 五轮均完成。
- 每个数字对照源数据；单位与统计一致。
- 术语、缩写、命名一致。
- 引文已核实、风格一致。
- 图表引用与编号正确。
- LaTeX/标记/数学完整。
- 无 AI 腔簇、无模板连接、无无依据形容词。
- 每段一个动作、有主题句、概念已落地。
- 朗读一遍；需要读第二遍的句子重写。
- 待作者核实问题已列出，不静默猜测。
