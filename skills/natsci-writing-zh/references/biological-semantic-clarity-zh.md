# 生物学语义、术语落地与结构可读性

版本 1.2.6.8；更新 2026-11-24。用于含蛋白、突变、结构、模型分数、实验数据或内部项目编号的完整 HTML、图题和图注。

## 必须通过的理解测试

未参加项目的结构生物学读者应能直接回答：研究对象是什么；模型计算了什么；分数的正负号表示什么；结构图显示的是哪一个蛋白或局部；颜色、透明、侧链和残基标签各表示什么；结果相对哪个基线成立；证据止于哪里。

## 术语和主语

- 缩写首次出现时展开：GB1 为链球菌蛋白 G 的 B1 结构域；1PGA 为 GB1 的实验结构；Olson 数据指 Olson 等 2014 年的 GB1–IgG 结合数据。
- 原始分数 q、位点分数 Q、留出 R² 和 ΔR² 首次出现时分别定义。
- q 的正负号若由候选方向定义，只表示评分方向，不表示提高或降低结合。
- 读者正文不用 `panel`、`局部操作变量`、`操作方向`、`操作图`、`身份匹配`、`空间语法`、`证据层`、`证据维度`、`增量面板`、`可检测`。改写为具体对象、动作和测量。
- 图注逐项使用 `a，…… b，……`，不使用“面板”。内部任务编号只放在来源索引中。

## 结构图可读性

- 一个结构 panel 只放一个分子对象。完整视图和独立局部视图分别占不同 panel。
- 非重点 Cartoon 使用 ChimeraX `transparency 20`，即约 80% 可见，并加入轻微白色景深；未突出显示的主链和二级结构必须能辨认。
- 关键残基保持不透明 Cartoon，同时显示 side-chain sticks。
- 局部视图在命中残基两侧至少保留 6 个残基，比只显示口袋的裁切宽约 20%。
- 残基标签使用 Arial，按最终 HTML CSS 宽度计算为 5–7 pt；1600 px 结构画布通常以 48–56 px source label 为起点。
- 标签直接写 `A86` 或 `A86–E88`，真实 PDB 编号与构造编号在源表中同时保留。
- 投影图覆盖当前全部主体：坐标范围由最长 x/y 跨度统一确定并最多留 6% 边距，记录零裁切；
  PCA/t-SNE/UMAP 的 x/y 单位长度相同，避免一个轴把另一个轴压成细线。

## 回归原因

- 72%、50%、30% 和 25% transparency 仍可能使结构背景过于微弱；本项目采用 20% transparency，即约 80% 可见。
- 60 px structure label 在缩小后的综合图里显得过大；应缩为约 52 px 并复算有效字号。
- 只显示口袋的局部裁切让读者失去结构上下文；应扩大窗口约 20%。
- 同一 panel 内全景加局部 inset 会被读成两个大小不同的蛋白对象；应拆成合同声明的两个 panel。
- 早期 0.40w 的行列完整边界净空对 BioNoether 偏大；作者要求缩小约 30%，实现、审计和
  文字统一采用 0.27–0.29w，默认 0.28w。
- 既往几何、颜色和哈希 PASS 不能证明语义可理解或视觉层级正确。
