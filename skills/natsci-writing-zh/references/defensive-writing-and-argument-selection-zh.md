# 防御性写作与论证取舍

在改任何一句话之前先读这一份：它决定**论文敢主张什么、敢舍弃什么**。句子表面的问题归 `writing-diagnostics-zh.md`；论证的归属在这里。

## 〇、两种失败看起来是同一件事

| 失败 | 审稿人看到的东西 | 根因 |
|---|---|---|
| **防御性写作** | 论文在反驳自己：每个主张都自带反方意见，局限出现在贡献之前，结论撤回摘要的承诺。 | 写给想象中的敌意审稿人，而不是写给想知道结果的读者。 |
| **AI 腔** | 论文什么都不主张：段落对称、章节等长，句子信息量看着不少，却找不到对象、数字和机制。 | 写的是段落的形状，而不是段落的内容。 |

两者的解法是同一个动作：**先决定这篇论文赢哪一场，再把每一段都花在那一场上。**

## 一、发布会原则

论文是一场学术发布会，不是项目总结、实验日志或自我审查报告。任务不是平均展示工作的所有侧面，而是识别最值得发表的价值，围绕它建立最有利的**完整**叙事。"完整"是关键：完整指必需元素齐备，不指把所有能算的东西都写进去。

## 二、论证取舍（在措辞之前完成）

**2.1 找到只有这篇论文才有的那一件事。** 候选优势包括：新能力；新问题；新机制；新尺度或新regime；让既有主张失效的更严格检验；成本、速度或数据优势；被量化而不是被声称的权衡。若有两个并列候选，说明还没有头条——选一个证据能独立撑住的。

**2.2 三问测试。** 用三句话回答，不许用形容词：
1. 我们赢的是什么——具体到关系，不具体到题目。
2. 赢多少，用什么量度，对谁比。
3. 凭什么成立——在哪个条件、体系或区段里这个主张是被挣来的。
第 2 问没有数字、第 3 问没有条件，说明这篇论文还没到"写"的阶段，只到"做"的阶段。

**2.3 选择战场。** 你没有义务参加打不赢的比赛。输掉的指标不自动等于主指标：改任务定义、改评价维度、改工作区间、改约束条件或改比较口径，让它们反映工作真正确立了的东西——**然后说清你赢的是哪一场**。这是选择，不是话术：新口径必须自身站得住，而读者会自然沿用的旧口径不能被隐瞒。

**2.4 篇幅跟着论证走，不跟着工作量走。** 实验日志式论文最典型的破绽：每个图配一节，每个实验配一段，因为每个实验花的钱一样多。按证据分量分配文字：三个月的阴性对照是一句话，决定性实验是半页。

**2.5 禁止流水账。** 不写"我们先做了什么、后来又试了什么、哪些失败了"。只保留站得住的逻辑：问题为什么重要 → 现有方法为什么不够 → 本文提供了什么 → 证据如何支持。失败分支只在它能排除读者本来会持有的替代解释时才出现。

**2.6 允许并有时必须重构故事。** 结果撑不住原叙事时，不要为原叙事辩护。重选主结果、重排贡献、改写题目摘要引言与图序，并在 claim ledger 里记下这次改动。忠诚属于证据，不属于最初的计划。

## 三、每个实验承担且只承担一项职责

实验是论证工具，不是结果仓库。动笔前先给每个实验指派一项职责并写下来：

| 职责 | 回答什么 | 通常位置 |
|---|---|---|
| **存在** | 效应到底有没有 | 第一个主图 |
| **机制** | 说的原因是不是原因 | 消融、扰动、回补 |
| **区间** | 在哪儿成立、在哪儿失效 | 留出体系、压力条件 |
| **排除** | 排掉了哪一种竞争解释 | 匹配对照、零模型 |
| **价值** | 对声称的用途是否重要 | 前瞻或应用面板 |

没有职责的实验：删掉、降级到补充材料或合并。有两个职责的实验，通常是一个实验加一条多余的主张。

## 四、分章节防御性审计

| 章节 | 典型防御性失败 | 控制 |
|---|---|---|
| 题目/摘要 | 局限爬升："……的初步探索" | 局限句为零。前五句写清问题、缺口、思路、头条数字。 |
| 引言 | 贡献尚未建立，先来一段"尽管本方法仍有不足"的预防性让步 | 在第一次说明本文做什么之前，不出现任何 caveat。 |
| 结果 | 主张没有数字、条件或对照；"值得注意的是……" | 每个小节以它确立的主张开头，每条主张带它的量度。 |
| 讨论 | 局限墙：三段落里散落 8–12 句自我审查 | **一段**局限，≤3 句，每句"条件→范围→后果"。其余 caveat 折进它所限定的那句结果里。 |
| 结论 | 末段突然的自我否定 | 末句是记忆点。不引入新局限，不以"未来工作"收尾。 |
| Cover letter | 为研究范围道歉 | 讲主张与它的量度、为什么现在重要、为什么契合。范围是一句话，不是忏悔。 |
| 回复信 | 为了显得随和，逐条让步 | 数据让步的才让步；其余用新证据回答。 |

## 五、修辞性减弱 vs 认识论校准

这是防止"反防御"变成过度主张的边界。

**删除测试。** 去掉这个限定词，再问：*细心的读者会不会因此被误导，以为测到了没测的东西？*
- **不会** → 修辞性减弱，删。("值得注意的是"、"在一定程度上"、"我们只是"、"或许")
- **会** → 校准，留；但要写具体：条件→范围→后果，且必须与它所限定的主张在同一句里。("在 34 个留出家族中——不含 12 个低同源家族——增益为 0.08。")

| 限定 | 诊断 | 处理 |
|---|---|---|
| "可能或许" | 冗余情态 | 删 |
| "在一定程度上" | 不可证伪的程度 | 换成被测到的程度 |
| "有待进一步研究" | 万能免责 | 删，或写成具体的开放问题 |
| "仅在大肠杆菌中" | 范围校准 | 留——贴在主张上，不要流放到讨论 |
| "n = 3、单一位点" | 功效/覆盖校准 | 留——并写出它对解读的后果 |
| "该测定无法区分 X 与 Y" | 测量局限 | 留——它界定了主张的边界 |

**绝对禁止——反防御规则从不授权下列行为：**
1. 没有证据的主张；没有测量过程的数字。
2. 删除会改变结果解读方式的局限——只能搬位置、压长度，不能删。
3. 用改写把阴性结果变成阳性；"未检出 X"就是"未检出 X"。
4. 从一个体系、一个位点、一个条件直接推到一类，除非写明桥接证据。
5. 隐瞒读者一定会问的对照、零模型或失败基线。
6. 本技能中的统计、报告诚信与 AI 使用规则高于本节任何风格偏好。风格买不到数据买不起的东西。

## 六、防御性藏在哪里

- 摘要前两句里的 caveat。
- 让步式开头堆叠："虽然……""尽管……""纵然……"成为默认句形。
- 局限散落：每节一小段道歉，以致任何一节都不能被单独引用。
- 双重主张："我们证明了 X，尽管只在 Y 中"写成一句，授予与撤回无法分开。
- 替审稿人提问："有人可能会质疑……""或许会有人认为……"——回答没有人提出的问题。
- 虚假谦逊："我们仅仅是"、"迈出的第一步"、"初步"。
- 补充材料当垃圾桶：把难看的放 Extended Data，正文假装不存在。
- 对称比较表：主动邀请一场会输的比赛，还放在主图里。
- 结论重新打开摘要已经关上的问题。

## 七、修订流程（论证层）

1. **主张清单**——列出全文所有主张，以及各自的量度与条件；标出无证据的。
2. **职责指派**——每个实验对一项职责；没有的对齐处理。
3. **战场**——说清赢的是哪一场；检查主图是否在打这一场。
4. **caveat 集中**——把全文道歉收拢到一处；限定具体主张的留下，其余删除。
5. **限定词分诊**——逐句做删除测试。
6. **开头与结尾**——把摘要前五句和结论末句当作一对来写；它们必须陈述同一个主张。
7. **读者测试**——把摘要给没看过这篇论文的人，请对方说出主张、量度、条件。说不出来，论证仍然是防御性的。

## 八、可执行门禁

运行 `python tools/check_prose_style.py --gate <文件>`，逐篇报告结构性指标。`--genre perspective` 放宽提案与理论文章的情态与局限上限（此处的可能性表述是校准）；`--genre report` 只报告度量、不作门禁。

| 指标 | 目标 | 说明 |
|---|---|---|
| 摘要中的局限句 | 0 | 人工 + `defensive.*` 命中 |
| 全文局限段落 | ≤1 | 人工 |
| 首句即主张的段落比例 | ≥80% | `--metrics` |
| 限定词密度 | ≤4/千词（英）、≤3/千字（中） | `--metrics` |
| 收尾总结句 | ≤1/千词 | `--metrics` |
| 句长变异系数 | 0.30–0.65 | 低于 0.30 是机器节奏 |
| 三项并列密度 | ≤1/500 词 | `--metrics` |
| 名词化比例（英） | ≤12% 实词 | `--metrics` |
| 破折号 | ≤2/千词 | `--metrics` |

## 九、用在两类信件上

- **Cover letter**：一段写主张与量度，一段写为什么现在重要，一段写契合度。不为范围道歉。
- **回复信**：先用审稿人的话复述每一条；用新证据回答；不接受的地方，说明你改做了什么、为什么足够。不要以"感谢审稿人指出不足"开头。

## 十、中文稿特有的防御性与 AI 腔

- **谦辞与自贬**：不揣浅陋、抛砖引玉、浅析、初探、以期、仅供参考、难免有疏漏——删；改为写清范围。
- **程序性叙述**："我们先……随后……最后……"、"本文首先回顾了……"——删；只保留站得住的逻辑。
- **空转定语**："具有一定的理论意义和实践价值"、"为……提供了新思路"、"在……背景下"——换成具体关系或删。
- **对称让步**："虽然……但是……"作为段落默认骨架；改写成两个肯定句，让步只在必要处出现一次。
- **四字格排比**：连续三个四字结构制造"文采"，通常不携带信息；保留信息量最大的那个。
- **局限集中**：全文只保留一段局限，位置在讨论末尾，三句以内，每句写明条件→范围→后果。
