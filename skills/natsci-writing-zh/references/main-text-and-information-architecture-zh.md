# 正文纪律与信息架构

版本 1.1.0；更新日期 2026-11-23。起草或压缩结果、决定正文与 Extended Data/补充材料的分配、审查稿件是否过长、把证据链映射到图和章节时阅读。

## 一、证据完整不等于正文完整

完整证据记录应保存在稿件、图、表、方法、源数据和补充材料中；正文空间只留给建立、推进或实质性限定核心断言的证据。压缩不得隐藏不利证据：若某观察改变结论方向、幅度、范围或可信度，即使名义上是稳健性或亚组分析，也必须在正文可见。

## 二、先给每个结果分类

| 类别 | 判定 | 默认去向 |
|---|---|---|
| 核心发现 | 推进核心结论 | 正文，证据充分 |
| 必要支撑 | 读者接受核心发现必须看到 | 正文，简短 |
| 限定 | 实质性限定或改变解释 | 是则正文，否则 SI |
| 稳健性 | 在替代设定/种子/阈值/估计量下结论不变 | SI，给指针 |
| 异质性 | 跨组/场景差异本身是断言一部分 | 核心则正文，否则 SI |
| 溯源细节 | 可追溯性、预处理、实现 | 方法/源数据/仓库/SI |
| 替代推断 | 同一断言的次要推断路径 | 除非改变接受度，否则 SI |
| 边界案例 | 改变断言解读方式的失效边界 | 改变解释则正文 |

按"在本论文中的功能"分类，不按分析名称。机制论文中的消融可以是核心发现；异质性可以是主结果；置信区间可以是主要推断证据。

## 三、最短充分证据链

写出让读者能够：
1. 理解核心观察；
2. 看到决定性比较或机制证据；
3. 判断主要不确定性或推断；
4. 理解改变结论的边界。

不要复现分析的时间顺序。分析和结果分配表稳定后再写结果叙述。

## 四、正文、图注与 SI 的分工

- **正文**：发现了什么、决定性支持、对核心断言意味着什么。
- **图注**：展示什么、如何阅读、理解图所需的定义。
- **SI**：结论为何经得起更深入审查（次要分析、稳健性、实现细节、扩展诊断、非核心边界）。

不要在正文和图注重复完整效应量、区间和 P 值。为完整数字报告选择一个权威位置，另一处只保留最低限度的叙述或阅读提示，同时保留期刊要求的图注内容。

## 五、展示项预算与信息密度

Nature Article：6 页约 2,500 词 + 4 个中等展示项；8 页约 4,300 词 + 5–6 项。一个中等展示项加图注约占四分之一页（约 270 词）。大拼图需要相应减少正文。正文参考文献通常不超过 50 条。

规则：每个图/表必须承担正文难以表达的断言、比较、机制或边界；不要为省预算把多个独立断言塞进一图；表不是数据堆，而是读者需要的比较；ED 承载必要支撑数据（Nature 允许不超过 10 个多面板项），SI 用于体量大或专门性强的必要材料；图注统计和方法从简，完整方案放方法/SI；一个强面板优于三个同结果的装饰变体。

## 六、防止返修膨胀

每次新增都触发删除检查：
1. 说明新句承担的功能；
2. 找出已承担该功能的句子；
3. 优先替换、合并或压缩；
4. 重读段落，删除因修改而冗余的句子；
5. 重跑段落必要性测试和断言重复审计。

审稿驱动修改时问：这句话告诉读者发现了什么，还是主要告诉审稿人某个反对意见为何不成立？必要的第一类保留在正文；第二类放 SI 或回复信，除非它对核心推断必不可少。回复信必须完整回答每位审稿人，即使正文改动很短。

## 七、段落必要性与解释递归

每个结果段问：删掉它，读者是否仍能理解并有足够证据支持核心断言？
- 不能：保留。
- 能，但审稿人可能要求：移到 SI 或回复信。
- 能，且观点在别处出现：删除。

正文不解释"解释"。若某统计或图形细节需要几句话才能与主结果调和，先简单陈述结果和改变结论的边界，再把详细调和移到 SI；只有当调和本身是发现时才留在正文。

## 八、断言重复图

一个主要断言可以被引入、证明和综合，但每次出现必须承担不同功能。在标题、过渡、图注、结果段、讨论和结尾句之间建立位置图，标记 introduce / demonstrate / interpret / synthesize / shorten / delete。删除不增加新证据、边界或解释的重复。

## 九、统计位置纪律

计算并保留设计、方案、报告标准和诚信审计要求的全部分析。正文通常报告理解效应所需的描述量和支持断言的主要推断统计量或区间；次要区间、替代估计量、多重检验、敏感性分析和模型层异质性放 SI，除非它们改变结论或期刊要求放正文。不得只选最有利的统计量；记录完整分析族和每个报告位置的理由。

## 十、可审计压缩记录

结果或全文重构时维护：
1. 结果分配表（结果、类别、对解释的影响、去向、指针）；
2. 最短证据链；
3. 删除日志（新增、替换、压缩、迁移、删除及理由）；
4. 统计位置记录（正文主报告、SI 次要分析）；
5. 断言重复图；
6. 每个修改小节的字数差。

记录保持简洁，除非用户要求完整表格；正文仍是交付物。

## 十一、不可妥协的例外

- 不因省字移除可复现性、诚信、安全、伦理或强制报告信息。
- 不把矛盾或改变结论的证据埋进 SI。
- 不删除防止误导性因果、临床、社会或泛化断言的限定。
- 不删除目标期刊、研究设计或领域标准要求的统计。
- 编辑要求放正文时照办，但仍先替换或压缩邻近冗余。

## 十二、信息架构审核

- 每个结果段是否都是核心断言所必需？
- 每个图/表是否有独立作用并放在正确位置？
- 正文承载证据而非实现清单？
- 完整统计是否只在定义位置报告一次？
- SI 是否包含稳健性与溯源而不隐藏改变结论的结果？
- 修改后是否避免摘要、结果、讨论和图注重复同一断言？
- 全部新增后字数是否仍在目标期刊预算内？
