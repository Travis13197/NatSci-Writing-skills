# Results 小标题：对象、过程、发现

版本 1.0；随 NatSci-Writing-skills 1.2.8.1 加入（2026-11-27）。

Results 小标题是科学标签，不是压缩后的口号。它要让没有读过论文的读者知道：研究了什么体系，测了什么。把图拿掉以后，标题仍然应当成立。

## 规则

1. 写出对象或体系，以及被测量的过程或结果。
2. 使用术语表中的具体名词：肽生长、终点结构、CATH topology、反应池、折叠富集、剂量响应、MD 稳定性。
3. 不用纯动词口号、隐喻、未定义的局部缩写，或把抽象名词当成整个标题。
4. 标题不超过 60 个字符、不超过十二个英文词。
5. 不以“我们”“本文”“本研究”或问句开头；不用标题式大写。
6. 标题与证据匹配：描述性标题可以陈述测量到的模式；因果标题必须有因果设计。
7. 各 Results 小节的语法形式保持平行。
8. 标题顺序构成叙事：体系、扰动、结构广度、反应条件、对照、边界。
9. 不在标题里首次引入新术语。
10. 60 个字符内说不清时，缩短主张，不要删掉对象。

## 反例与改法

- 规则偏置探索与折叠 -> 结构空间中的肽生长
- 路线视野重塑终点 -> 路线评分改变终点结构
- 414 个终点的结构图谱 -> 终点覆盖 44 个 CATH topology
- 全反应池维持折叠 -> 反应池维持结构谱系
- 对照分离规则驱动的折叠 -> 折叠富集通过对照
- 前生命化学与稳定性 -> 剂量响应与 MD 稳定性

反例失败在四点：主语缺失、把局部隐喻当成术语、动词承诺超过设计、标题写方法而不是发现。改法只保留具体对象与测量结果。

## 审计

投稿前列出每个 Results H3，逐一回答：对象是什么、测量是什么、条件是什么；缺一项就重写。然后检查长度、平行性和与图注标题的一致性。标题审计独立于 prose 门。
