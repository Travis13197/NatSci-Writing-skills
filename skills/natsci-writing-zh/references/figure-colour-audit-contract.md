# Nature/Science 级论文图件语义配色与颜色审计契约

版本：1.1.0；更新日期：2026-11-22。

## 1. 目标与边界

本契约用于论文主图、扩展数据图、结构图和 HTML 图组。目标是建立稳定语义、色盲可读、
灰度可辨、印刷可控的配色系统。Nature 和 Science 并不向作者提供一个可复制粘贴的
唯一 RGB 品牌色板；本契约采用其高水平论文常见的低饱和、层级明确、少类别高对比
配色原则，并以 Okabe–Ito 色相分离作为色盲安全基础。

## 2. 固定语义色

| 语义 | 色值 | 白底对比度 | 使用规则 |
|---|---|---:|---|
| 主模型/主结构 | `#0D5673` | 8.09 | 主要对象、query、核心比较 |
| 第二模型/预测 | `#4E8EAD` | 3.62 | 只作填充；文字使用深色 |
| 支持/确认 | `#16786F` | 5.32 | 通过、重复、独立确认 |
| 条件化/警戒 | `#C77A24` | 3.37 | 只作填充；文字使用深色 |
| 阴性/停止 | `#B8453E` | 5.31 | 失败、阻断、未通过门槛 |
| 正交验证 | `#6C5079` | 6.86 | 独立模型或不共享坐标的验证 |
| 中性 | `#586B75` | 5.56 | 背景、未支持、control |
| 正文/轴标签 | `#132B36` | 14.72 | 正文、轴标签、panel letter |

次蓝和琥珀在白底上低于正文文字所需的 4.5:1 对比度，不得作为 6–7 pt 小字颜色。
它们可用于柱、区域、点和线，同时配合深色刻度与直接标签。

## 3. 模型与结构映射

模型颜色采用同色系明度和有限强调色，不机械循环高饱和色板：

| 对象 | 默认颜色 | 冗余编码 |
|---|---|---|
| ESM2-8M | `#0D5673` | 实心圆 |
| ESM2-35M | `#4E8EAD` | 实心方 |
| ESMC-6B | `#6C5079` | 菱形 |
| ProtT5 | `#16786F` | 三角 |
| ProstT5 | `#4F8F7A` | 空心三角或虚线 |
| METL | `#586B75` | 叉号或灰色 |

三个结构位点固定使用琥珀、青绿和砖红，并在图注中写明残基编号。结构主体使用主蓝。
任何模型或位点在不同图中改变颜色时，需要独立作者核验记录和明确理由。

颜色首先绑定对象身份，状态另用非颜色通道编码。同一模型、系统、状态或残基在图组内
不得因为某个 panel 的通过/失败分类而换成另一种颜色；此类状态应改用 hatch、轮廓、
实心/空心、点形、线型或直接标注。摘要 panel 与轨迹、矩阵或结构 panel 的颜色语义
互相冲突时，图件拒绝发布。

## 4. 类别、连续量与发散量

- 定性 panel 默认最多 3 个彩色类别加 1 个中性色。
- 超过 3 类时优先增加点形、线型、分组、轮廓、透明度或直接标签。
- 连续量使用由浅到深的单调蓝阶。
- 双向偏离使用砖红—中性—深蓝发散色阶。
- 禁止 `jet`、`rainbow`、`hsv`、`gist_rainbow`。
- 禁止只靠红—绿、蓝—紫或深—浅色相编码关键状态。

## 5. 矩阵 panel

矩阵格内不写数值、字母、相关系数或 `yes / ~ / x`。单元状态用独立几何符号编码：

- 支持：实心圆；
- 部分支持或条件化：菱形；
- 不支持或停止：叉号或空心轮廓；
- 中性或无数据：留白或浅灰背景。

精确值保存在源表。颜色与符号必须同时出现。连续矩阵不放格内数字，不在热图上叠加
不透明白底注释框。

## 5A. 多重结构域与配体

同一蛋白质的结构域身份使用可区分的浅色，不通过高饱和类别色循环表达。默认域色为：

| 结构域 | 色值 | 冗余编码 |
|---|---|---|
| DBD | `#7FAFC8` | 直接 `DBD` 图例与残基范围 |
| hinge | `#79B9A9` | 直接 `hinge` 图例与残基范围 |
| LBD/EBD | `#C19AAD` | 直接 `LBD/EBD` 图例与残基范围 |
| N 端/连接区 | `#BFCBD2` | 中性上下文 |

配体使用红橙 `#D55E00` 球棍，原子边界使用白色描边，透明表面使用
`rgba(213, 94, 0, 0.20)`。深色化学键、配体名称和高对比原子球共同构成主视觉焦点。
轨迹中的配体使用逐帧坐标；模板锚定的配体使用同一蛋白坐标架，并在界面写出来源。
域色用于结构域身份，界面、hinge 和口袋位点的形状编码继续独立承担功能角色。

Cartoon 与 Cylinder 使用同一结构域和位点颜色。Cylinder 的深色边界使用同一基色的
低明度版本，白色高光只表达圆柱光照，不承担新的类别。两种表示的模式切换不能改变
配体红橙、关键位点、持续/新增/消失网络边和位移箭头的颜色。结构增强版与原始结构
panel、统计 panel、正文和图注继续共享同一语义映射。

## 6. 结构与统计统一

结构主体、位点、配体和统计 panel 使用同一颜色角色。统计图更新色板后，结构 PNG、
PDF、SVG 和 `.pse/.cxs` 必须同时重渲染。结构渲染记录：

- 源 PDB/CIF 及 SHA-256；
- 主体色、位点色、配体色；
- camera、zoom、orthographic 设置；
- ambient、direct、reflect、specular、shadows；
- 原始墨迹框和裁切框；
- 最终内容宽、高占比；
- PNG、PDF、SVG、结构会话和哈希。

## 7. 强制颜色审计文件

### `figure_color_audit.tsv`

逐 panel 至少记录：

`figure, axis_index, role, cmap_names, forbidden_cmap, matrix_texts_inside_cells,
chromatic_colors, n_chromatic_colors, unregistered_colors,
minimum_text_contrast_to_white, text_colors`

### `figure_palette_roles.csv`

记录全部语义角色与色值。若一个颜色承担两个语义，必须拆分。

### `STRUCTURE_RENDER.json`

记录结构色板、相机、光照、源结构、墨迹与裁切测量、会话和导出哈希。

## 8. 拒绝发布的硬条件

- 出现未注册颜色；
- 使用禁用色图；
- 白底文字对比度低于 4.5:1；
- 矩阵格内文字数大于 0；
- 类别比较仅依赖颜色；
- 同一对象在正文、统计图、结构图或图注中使用不同颜色；
- 统计图已重绘但结构图仍是旧色板；
- 结构 raster 未测量墨迹框、裁切框或内容占空率；
- 只报告几何和字号 PASS，没有颜色审计。
- Cartoon 与 Cylinder 使用不同结构域或位点颜色，导致模式切换改变对象身份。
- 圆柱高光被当作第二类别颜色，或圆柱边界与网络边使用相同层级。

## 9. 本项目已确认的高频错误

1. 给每个模型分配一个高饱和色相，形成彩虹分类。
2. 同图蓝色、紫色、粉色饱和度不一致，打印后主次关系反转。
3. 在热图格内写 `C / p / -`、相关系数或 `yes / ~ / x`。
4. 只用颜色表示支持、条件化和阴性。
5. 浅蓝、灰色或亮琥珀小字直接放在白底。
6. 旧 PyMOL 结构仍是蓝绿红高饱和色，而统计 panel 已换新色。
7. 结构图只输出 PNG，没有 PDB SHA、结构会话和渲染记录。
8. 先按未裁切 PyMOL 画布分配行高，产生内部大片白区。
9. 在旧网格上强行 `set_box_aspect(1)`，坐标框方形但拼图仍有大块空白。
10. 使用透明度、阴影或高光掩盖遮挡，降低打印可读性。
