# 图件技艺、证据架构与信息密度

版本 1.2.6.8；更新日期 2026-11-24。规划或审核多面板图、决定主图与 Extended Data/补充材料的分工、判断视觉层级与信息密度、设计示意图或图形摘要时阅读。配合 figure-production-zh.md、figure-standards-nature-science-zh.md 与项目图件叠加规范。

## 一、从图级断言开始

绘图前写：

~~~
结果层问题：
图级断言（一句带动词）：
什么能推翻它：
决定性证据：
面板序列：a — 作用；b — 作用；c — 作用
被移出材料去向：主图 / 另一图 / ED / SI
~~~

一幅图通常回答一个结果层问题。若所有面板都为同一高层断言的建立、限定或边界服务，可以包含多个从属发现；若某面板建立独立主要断言，应另立一图。

面板字母标记阅读顺序，不分配固定功能。a 不必是示意图，d 不必是压力测试。

## 二、让面板承担不同推断角色

| 角色 | 回答的问题 |
|---|---|
| 体系/示意 | 测试什么系统、干预或对照？ |
| 代表性实例 | 现象在具体案例中什么样？ |
| 主要定量证据 | 核心效应或能力是否存在？ |
| 基线/对照 | 是否超过可信替代或经受对照？ |
| 分解 | 哪些成分或变量解释效应？ |
| 分层 | 是否在重要条件下成立？ |
| 正交验证 | 是否用另一实验或证据类型复现？ |
| 扰动/压力测试 | 是否经受攻击，或在必要关系被破坏时如预测失败？ |
| 边界/失败案例 | 在哪里减弱、反转或停止泛化？ |
| 机制证据 | 支持什么有边界的解释？ |

面板应各自必要，而不是各自讲故事。移除一块应去掉其他面板无法恢复的推断步骤。角色多样性优先于指标多样性。

弱镜像布局：a: R2 → b: R2 成对检验 → c: MAPE → d: MAPE 成对检验；常常只有两个角色。
较强链条：a: 扰动设计 → b: 决定性比较 → c: 完整分布/残差 → d: 分解或边界。

## 三、证据链原型

- **验证包络**（系统/干预/模型是否可信）：定义能力 → 建立 → 测试不同失效模式（一致性、泄漏、安全、偏差、稳健性）→ 攻击 → 限定边界。
- **从尺度到实例**（群体模式需要解释）：全局图/分布 → 数量 → 空间关系/尺度 → 内部结构 → 有信息量的例外。
- **发现序列**：假设 → 决定性实验 → 分析 → 修正假设 → 下一个检验 → 机制验证。
- **能力阶梯**（方法论文）：是什么 → 学到什么行为 → 是否优于替代 → 增益是否经受更难条件 → 什么更广能力随之而来。

跨原型的可复用图级链条：建立 → 比较/对照 → 压力测试/区分 → 扩展 → 限定。只使用断言需要的动作。

## 四、图序与断言升级对齐

跨图时，每幅图应提出更强或不同的断言，并制造下一个科学问题。示例原型：图 1 是什么 → 图 2 评价/资源是否可信 → 图 3 现象是否存在 → 图 4 是否优于替代 → 图 5 是否经受更难条件 → 图 6 什么机制、普适性或边界随之而来。

若两幅图都能概括为"X 表现好"，合并、降级较弱证据，或让后一幅图问更深的问题。

## 五、视觉层级来自证据层级

- 决定性证据放在 hero 位置或最大面积。
- 对照与稳健性视觉更安静，但足以判断。
- 全图使用同一条件/队列/方法映射。
- 推断重要性不同时，不强求等大面板；不因习惯加装饰性 a 面板。
- 当攻击、阴性结果或失效边界改变图级断言时，让它可见。
- 面板间邀请直接比较时，坐标轴、不确定性、n、比较标签保持一致；改变 n/分母/队列/估计量/尺度须披露。

## 六、面板必要性与去向

1. 移除它，哪个独特推断消失？
2. 该推断是否建立、推进、限定或界定图级断言？
3. 它是独立角色，还是同一结果换指标/种子/阈值/编码？

去向：主图（决定性证据、必要对照、核心证伪、改变结论的边界）；ED/SI（安抚性、溯源、次要指标、替代估计量、扩展亚组）；另一图（真正独立的主要断言或下一阶梯）；删除/合并（无独立推断增益的重复视图）。

不得因布局不便隐藏改变结论的阴性结果。

## 七、信息密度

- 一个面板一个数据图；面板内不用 inset axes、子图拼贴、facet 网格、嵌套色标或多个微型图。
- 信息密度是角色多样性，不是指标更多。有源数据时，只有均值柱而不给 n 或分布的面板信息不足。
- 展示分布（点、箱、小提琴、区间），而不是只给汇总柱，除非有理由。
- 关键比较直接标注，避免图例寻宝。
- 颜色角色稳定且有限；证据状态同时用填充、形状、网纹、轮廓编码。
- 删除图表垃圾：3D、渐变、阴影、装饰图标、重网格、彩色文字、无解释坐标轴。
- 拼图不可读时扩大画布、拆图或移入 ED，不把字号压到期刊下限以下。
- 大数据不等于多面板；少量决定性比较加源数据常常信息量更高。
- 同一估计量换图型、阈值、seed 或配色不构成新 panel。第九 panel 必须回答前八 panel 未覆盖的分母、失败状态、配对轨迹、阈值敏感性、留出验证或机制分解。
- 每个 panel 的 `panel_role_audit.tsv` 记录样本点、线条、柱、区间、矩阵、阈值和直接标注。两个 panel 的源表、变换和阅读路径相同即判重复；删去或替换为样本级恢复轨迹、状态组成或独立验证。
- 低行数也不能退回孤立均值柱。3–10 个条件可用前后配对轨道、分母解剖、效应–不确定性格栅、状态矩阵或同时显示总量与区间的短森林图。
- 图件足够清楚以后复查最终 HTML 有效字号。源 raster 被页面缩小后，10 pt 不再等于 10 pt；同时检查 raster/CSS 宽、保存 dpi 和每类文字的有效 pt。
- 长度、时间、剂量和信息层级本身有序时，使用连续数值轴，并用颜色、点形和网纹区分动作核或条件。不要把 12–24 个“长度×动作”组合逐个排成分类刻度；这类分类轴会拉宽图片、缩小 axes，并让失败状态变成不可读的长标签。
- 失败状态、完成者和未定义分母按连续长度或剂量定位。分组柱位置可以围绕同一数值中心偏移，动作核使用 hatch、轮廓或点形冗余；完整类别名留在图例、图注和源表。

## 八、Nature 正刊图件要求（投稿前核对）

- 首次投稿：图可嵌入正文；不要求制作级；图注与图同页；数据须可评估。
- 图注：首次投稿完整图注少于 250 词；以标题句开头；描述展示内容；写 n、重复定义、中心/离散度、误差棒、检验、校正与 P 值显示；不叙述结果或方法。
- 制作主图：单栏 89 mm 或双栏 183 mm；高度不超过 170 mm；最终字号 5–7 pt；面板字母 8 pt 粗体正体小写 a、b、c；Arial/Helvetica；氨基酸序列用 Courier；文字可编辑；矢量格式（.ai、.eps、可编辑 .pdf；分层 PSD、PDF 转换的 PowerPoint、SVG、Excel、PS 视指南接受）；不用扁平 JPEG/TIFF/PNG 作为最终主图制作文件；单文件目标小于 50 MB。
- ED 制作：RGB、不超过 300 dpi、单文件不超过 10 MB、优先 JPEG 或 TIFF/EPS、每项一页、按作者姓氏与 ED 编号命名。
- 可及性：保留轴线与刻度；坐标轴与单位标注；色盲友好、避免红绿或彩虹依赖；无网格/阴影/装饰图案/彩色文字；比例尺可编辑且校准；RGB；照片不低于 300 dpi（最好 450 dpi）。
- 图像诚信：原始文件、裁剪、对比度/gamma、伪彩、拼接、泳道重排、处理软件、复用；遵循期刊图像诚信政策。
- ED 不超过 10 个多面板项；SI 用于必要的大体量/专门材料；每项在正文引用。

不要把首次投稿要求与原则接收制作要求混为一谈。

## 九、矢量示意图与图形摘要

- 读者必须先理解系统、流程、机制或 agent 循环时，用矢量示意图。
- 字体：一个家族、最多三种字号；Nature 最终尺寸正文 5–7 pt；一种深色墨；只加粗顶层组名；标签使用稿件术语。
- 颜色：白底；最多两种饱和填充，且只有一个强调色标记本文新组件；既有部分用浅色/灰；红色只用于错误/瓶颈；不用彩虹、渐变、3D、阴影；不只靠颜色。
- 线条：每条有向边有箭头；主路径最重；虚线全图只有一种含义；结构用正交路径，反馈用曲线；连接线接边中点；不穿过标签；线与框边留可见间隙。
- 结构：嵌套不超过三层；框对齐网格；间距相等；同类容器内部顺序一致；重复用 ×N 或两层偏移框，不复制 N 份。
- 图例：超过四种填充/线型/图标才需要；放在被解码对象一个框宽内；主路径边用圆圈数字并与图注 walkthrough 对应。
- Agent/工具图：把 agent 画成迭代循环（推理 → 调用工具 → 观察），工具作为被调用者按模块分组，检索是工具调用而非流水线阶段；比较模型时写出模型名。
- 图形摘要：是示意图，不是编造数据或装饰插画；不得暗示不存在的结构、结果或定量断言；使用矢量流程，标签与颜色角色和正文一致。AI 生成图只在披露且不暗示数据时作为插画；绝不用它表示实验结果。

## 十、图型速查

| 图型 | 适用 | 避免 |
|---|---|---|
| 横向柱 | 方法/组别排序比较，带不确定性 | 连续趋势；隐藏分布 |
| 线/趋势 | 时间、剂量、有序条件 | 名义类别；少数时间点且不确定性大 |
| 散点 | 两个测量变量的关系 | 无密度/透明度策略的过绘 |
| 箱/小提琴+点 | 组间分布 | n 太小，只应展示个体点 |
| 热图 | 多条件/特征矩阵 | 任意排序；彩虹色；格内文字 |
| 森林/区间 | 亚组效应与 CI | 无参考线或尺度解释 |
| 堆叠面积/柱 | 组成随时间/组变化 | 精确比较；类别超过约 5 个 |
| 雷达 | 多基准、各轴独立标准化 | 一般比较；隐藏量级 |
| 网络 | 关系/架构 | 无布局目的的毛球 |
| 图像板 | 显微/成像证据 | 无比例尺、对照和定量 |
| 示意图 | 系统/机制/流程 | 无信息作用的装饰面板 |

## 十一、图件审核

- 图级断言能否一句带动词说清？
- 每个面板是否有独立推断角色和必要比较？
- 面板顺序是否形成链条而不是仪表盘？
- 决定性证据是否视觉主导，对照更安静但可读？
- 核心攻击、阴性结果和边界是否可见？
- 信息密度是否合适（分布、n、不确定性、直接标注），而不是只有汇总？
- 期刊栏宽、字号、面板字母、文件格式、图注限制是否在记录阶段满足？
- 图序、结果断言和讨论综合是否逐级升级而非重复？
- 图注能否解释展示内容而不复述结果？
- 最终物理尺寸下所有标签、刻度和注释是否可读且无遮挡？

## 十二、AI 生成视觉内容

AI 生成图像不是证据。期刊允许时，概念示意图和图形摘要可用 AI，前提是标明概念性、作者核验每个标签和关系、存档溯源记录。数据图仍由真实数据和代码生成。AI 辅助排版、颜色或字体可以披露后使用；AI 生成文字标签要重做并核对。禁止：合成数据图像、生成式填充/移除物体、凭空增加细节的 AI 放大、编造结构、假比例尺或显著性标记、封面/图形摘要不披露 AI、prompt 含版权或患者材料。读 ai-figures-and-visual-integrity-zh.md。

## 十三、v1.2.6.3 图例与统计信息密度

图例占据独立信息空间，不占据数据空间。短系列使用一个词标签；两个词只保留必要缩写，
完整定义放在图注和源表。直接标签至多承载四个系列，并在 axes fraction 中保持整组最小
间距；系列更多时改为图题下方横排或右侧独立列。legend、direct label 和 series text
都进入数据遮挡审核。

显著性是统计证据，不是装饰。只在有真实比较时，对 bar、box 和 violin 添加括号；括号
必须对应同一分组、独立单位、分母和对照方向。Forest 的 q 值使用独立外置列。没有检验
时空缺保持为空，不生成星号。分布图中 violin、box 和样本点同时保留透明度，使形状、
统计量与单点分布都可见。

当数据贴住坐标上限时，先检查是否应展示差值、恢复量或完成量变化；如果原比例仍是最佳
估计量，则增加上侧 headroom，而不用任意截断或放大轴制造差异。

## 十四、v1.2.6.4 统计信息密度

显著性使用 `****/***/**/*/n.s.`，精确 q 值离开绘图区。连续效应图把 CI 和星号放在同一点，
同一显著区段只选首、中、末代表点，避免星号比数据更密。森林图的星号列与点区间一一对齐。
图例先横排在图题下方，只有横向空间不足才进入端点或右侧。状态转移用 `C/T/B→C/T/B`
短码，完整状态和 q 值进入图注与源表。
