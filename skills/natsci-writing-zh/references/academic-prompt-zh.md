# 课题构思、文献调研与科学 HTML 全文修订提示词

版本：1.1.0；更新日期：2026-11-23。以下提示词可直接用于研究设计、完整论文起草、学术写作、图件生产、期刊格式调整、审稿回复与整篇科学 HTML 修订。执行时依据当前明确提出的任务选择相应工作；完整润色覆盖所指定文件的全部科学内容。

## 通用完整提示词

请以人工智能与生物学交叉领域高水平原创研究的专业深度，按照 Nature、Science 等顶级期刊所体现的论证结构、证据标准、语言风格和图件规范开展工作。研究构思围绕明确的生物学问题，提出具有原创性和非平凡科学洞见的研究课题，说明其科学价值，并建立中心假设、研究目标、关键预测、研究内容与验证路径之间的完整联系。用机制解释、具有区分力的预测和能够回答关键问题的实验体现思想深度，而不是用"首次""颠覆""填补空白"等评价性语言宣称创新。

写作遵循顶级期刊的五个基本要求。第一，先立论后铺陈：摘要、结果小节和讨论段落的第一句给出发现或问题，不写领域编年史。第二，具体先于抽象：每个句子写明分子、残基、数据集、模型量、比较对象或测量，不用抽象名词充当句子骨架。第三，证据决定语气：观察到、测量到、相关、预测、提出各用对应动词，限定语只在影响解释处写一次。第四，一段一个动作：背景、缺口、方法、结果、解释、局限分开组织，不写清单段和模块目录。第五，读者经济：删除不改变读者判断的文字，自然学术表达比生成文本更短、更具体。

摘要按"领域现状—具体缺口—方法与系统—关键结果（含数字和比较）—科学意义"组织。Nature 研究论文摘要约 200 词、7–8 句，用"Here we show"或等价句式引出主要结论；Science 研究论文摘要约 125 词、6 句，以具体推论收尾。综述摘要 120–200 词，Perspective 使用个人视角、前瞻而平衡的论证；Science Perspective 的提要为一句约 11 词。引言把已知写成能力而非文献清单，指出尚未解决的关系和现有方法为何不能解决，末段预告结果的形态。结果按"问题—设计—观察与统计—推论"组织，小标题是主张而不是模块名。讨论写出核心推进、对竞争解释的约束、与最近研究的关系、最有区分力的后续检验和具体科学意义；局限以科学条件的形式出现一次，不做防御性罗列。

语言应当科学、专业、自然。中文单句以 25–55 字为宜，研究论文段落 150–260 字，综述 200–350 字，Perspective 可以更长以保持论证连续；长短句交替，每段有主题句。优先"主语—动词—宾语"，把"对……进行……"式名词化改成动词句。数字带单位、比较和分母；统计写清 n、中心与离散度、检验和校正。删除"此外、同时、值得注意的是、综上所述"式连接词空转；只有在真实因果或转折处使用连接成分。逐句改写"不是……而是……""并非……而是……""不仅……而且……"等模板化对立，直接写出支持该判断的证据。删除评价性形容词（颠覆性、全面、鲁棒、无缝、前沿、state-of-the-art）和防御性套话（在一定程度上、有望、尚需进一步验证），换成可测量的性质或具体条件。

成稿后按 AI 标记词表自查：每千词命中数应保持在个位数，且多数应为统计或技术用法；一段内出现两个以上"此外/值得注意的是"或三个以上评价性形容词，视为不合格段落。逐段问"读者现在知道了什么"，答不上来就删除或合并。全文朗读一遍，需要读第二遍才能解析的句子重写。

完整论文任务先建立一句话论证、论文类型、术语表与段落地图，按"结果 → 引言/结论 → 标题 → 讨论 → 方法 → 摘要"的顺序起草，最后交付标题页、摘要、正文、方法、参考文献、图注、扩展数据、数据/代码/贡献/利益冲突声明和缺失输入清单。图件任务先写图件合同（结论、原型、面板地图、证据层级、统计、源数据、审稿风险），再选择 Python 或 R 后端并在该后端内完成绘图、预览、导出和视觉 QA；不得用另一种语言替代。每幅图一个论断，面板按"体系/设计 → 主要比较 → 机制/定位 → 量化 → 稳健性/验证"排列，图注写清 n、误差定义、检验与校正，导出 SVG/PDF 可编辑矢量与 300–600 dpi 位图，并记录面板几何、颜色角色、遮挡和源数据映射。

图件按"一幅图一个论断"设计。绘图前用一句陈述句写出该图建立的论断；面板顺序按读者推理路径组织：背景、设计、主要比较、稳健性或独立验证、机制。Nature 图件单栏 89 mm、双栏 183 mm，面板字母 8 pt 粗体小写 a、b、c，其余文字 5–7 pt，线宽 0.25–1 pt，位图 300–600 dpi，优先 EPS/PDF/AI 矢量；Science 图件单栏 55 mm、1.5 栏 120 mm、双栏 183 mm，面板字母大写粗体 A、B、C，字号 5–7 pt，照片不低于 300 dpi、线条图 600 dpi。图注写成五段式：标题论断句、逐面板说明、统计与重复（n、n 的定义、中心与离散度、检验、校正）、符号与缩写、来源与许可；研究论文图注 100–220 词。误差棒必须写明 s.d.、s.e.m.、95% CI 或 IQR；基准比较写明基线、指标定义和评价单位。

开展研究构思或更新研究框架时，进行完整、围绕科学问题组织的网络调研。检索奠基研究、最接近的原始研究、竞争性解释、相关技术和截至检索日期的前沿结果。优先阅读原始论文、正式发表页面、可信预印本、原始数据库和作者数据及代码。核对题名、作者、年份、发表状态与 DOI，记录检索日期和实际阅读范围。按科学问题综合文献，解释证据之间的一致、差异来源和仍待回答的问题；每一项重要背景判断、数值和机制陈述都要有可追溯来源。

综合调研形成具有内在逻辑的课题框架：明确研究对象、中心假设和预期解释的现象；为每个研究目标明确实验系统、干预、测量、比较、对照、分析单位和科学推论；围绕主要竞争性解释设计能产生不同预测的实验，安排独立验证、机制研究和稳健性分析；用具体预测说明新认识，并准确比较与最接近研究的实质推进。拟开展的研究用计划性表述，预期结果用预测性表述，已有发现对应实际证据。

若任务涉及已有 HTML，先完整阅读指定文件及全部注释，建立按阅读顺序排列的内容清单，覆盖标题、摘要、章节、段落、图注、表格说明、公式解释、脚注、附录、参考文献、折叠面板和动态文字。大型文件分段读取并记录已读范围，补齐截断内容。基于全文理解逐句修改，保留准确、自然的既有句子；统一术语、编号、统计口径和段落关系，保证正文、图表与结论一致。

同步检查数据真实性和计算：把关键数值、数据规模、统计结果、模型比较和机制结论追溯到原始数据、代码或文献；检查样本定义、纳入排除、分析单位、分子分母、缺失值、重复、单位、归一化、聚合、排名和百分比；核对统计检验、独立重复、零模型、多重校正、效应量和不确定性；检查训练、特征选择、预处理、校准和测试之间的隔离。依据可用输入复算影响结论的关键数值，核对公式与实际实现、表格图像与正文的一致性。明确区分"按报告值做算术核对"和"从原始输入重现分析"。

依据核实结果修正文稿，保留原始数据和分析记录。为重要更正记录原值、修正值、来源和理由。尚待补充的源文件和实质问题写入独立作者核验记录，正文使用证据支持的准确表述。不编造实验、数值、统计、引文、资源链接和完成状态。

完成后生成新的、可直接阅读的 HTML，默认保留原文件。维护章节结构、连贯正文、图表位置、公式呈现、引用、导航和必要交互，采用 UTF-8 和可读排版。完成科学逻辑与证据核查、逐句语言与术语核查两轮复读，核对内容块覆盖。检查最终文件、资源路径、导航锚点和公式渲染；具备浏览器工具时进行实际页面检查。交付时说明文件路径、实际完成范围和需要作者处理的实质事项。

## 中文学术论文适配

目标为中文论文时，直接用符合中文学术习惯的完整段落构思和写作。保持问题、方法、证据、解释和意义的递进；采用准确、自然的中文句法，避免英文句式直译、80 字以上长定语和抽象名词连续堆叠。专业缩写在首次使用时给出中文名称、英文全称和缩写；基因、蛋白质、物种、单位及统计符号遵循学科规范。

中文特有的删除项：连续三个"的"的定语链；"进行、开展、实现、完成、加以"后接名词的弱动词结构；"被广泛认为、被发现、被用于"的被动堆叠；"情况、问题、方面、过程、现象"等冗余范畴词；"这使得……成为可能""对于……而言""在……的过程中"等英文从句直译。连接词"然而、因此"放句首自然，但不宜每段都用；段间关系可以通过重复关键词建立。

中文正文与英文摘要或术语对照共同交付时，核对研究对象、数值、方向、比较和证据强度一致。单独请求中文论文时交付完整中文稿。用户要求修订对照时，把相对最新原稿新增和替换的文字加粗；要求最终清稿或全篇 HTML 时移除修订加粗。科学数据表和公式按需要保留，编辑清单和核验记录放在正文之外。

## 图件有效字号与固定拼图复核提示词

请对全部主图、补充图和生成过程图按最终 HTML 显示尺寸做一次回归。逐图读取源 PNG 宽高、保存 dpi、页面 CSS 显示宽、每个 axes 的最终像素矩形、每类文字角色的原始 pt，并计算有效 CSS pt；报告小于 10 pt 的普通文字、小于 10.5 pt 的轴标题和任一因长 y 标签而异常扩张的列 cell。固定 3×3 图的物理 canvas、axes 尺寸与完整 cell 净空，禁止单个图例或比较名改变列宽；比较名在刻度轨缩写，完整 estimand 保留在轴标题、图注和源表。长度、时间、剂量和信息层级使用连续数值轴，动作核和条件用颜色、点形、网纹编码，不把组合展开成十几到二十几个分类刻度。保存阶段不得用 `bbox_inches="tight"` 或内部空白压缩改写已审计 gutter。逐 panel 记录样本、区间、矩阵、阈值和直接标注，删除同一估计量只换图型或阈值的重复 panel。完成后输出图件级与逐 panel 审计表，并在 1440、390 和 320 px 浏览器中展开全部折叠图库检查所有图像、文字和媒体。

## v1.2.6.3 图例、刻度与显著性复核提示词

逐个 panel 检查图例、直接标签和系列文字是否覆盖点、线、区间、柱、矩阵或结构。短系列
使用一个词缩写；超过四个系列不使用图内直接标签，改放到标题下方横排或右侧独立列。
直接标签使用稳定坐标并保留最小间距，最终 panel 缩放后重测。不得在解决刻度碰撞时删除
x/y 轴标题；每个轴至少保留两个可解释刻度。分类刻度缩写后按实际 bbox 均匀稀疏，
数值轴保留 4–6 个主要刻度。

panel 字母和标题必须依据顶部刻度实际高度动态上移，最终拼图后重新测量。线性轴极值不得
贴住边框；非负比例保留零基线并增加上侧余量，必要时改用相对基线的差值或恢复量。所有
显著性括号只标记真实比较，报告校正 q 值；forest 的 q 值放在绘图区外；没有正式比较时
保持空白。分布叠加图的点、violin 和 box 保持合适透明度。最后要求
`zero_text_collisions`、`zero_legend_data_occlusion`、`axis_tick_completeness` 和
`typography_compliant` 全部通过，并逐 panel 复核拼图。

## v1.2.6.4 星号显著性、区间和顶部图例提示词

逐图检查所有显著性，只保留标准星号 `****/***/**/*/n.s.`，完整 q 值放到图注和源表。
连续效应必须同时显示 95% CI 带；一个连续显著区段标首、中、末代表点，显著状态变化和

## v1.2.6.6 投影范围、结构 cartoon 与 HTML 强调提示词

逐个检查 PCA/t-SNE/UMAP：范围是否由当前完整数据计算，x/y 是否等单位和方形数据框，
是否存在越界点，刻度是否显式且没有沿用旧范围。投影被压成细线或中央密集点时重画。

折叠结构使用真实 cartoon/ribbon；非重点链、loop 与上下文使用灰色 20% 透明度
（约 80% 可见），焦点结构不透明，标签带不压分子。HTML 中结果主题句、关键数字、逻辑
转折、摘要结论和图注推断句分别加粗，每段 1–3 处。最终在每幅图的页面位置截图核验。
