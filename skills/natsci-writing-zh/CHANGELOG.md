# 变更记录

## 1.2.6.8 — 2026-11-25

- 重排增补：对数轴可能放大行高测量，留下大块内部空白，即使所有图元都在坐标轴内。若图版出现无法解释的空白带，先检查对数轴；动态范围不大时改用线性轴，或显式预留垂直空间并重跑内容范围审计。

- 可见体增补：审计 PolyCollection/LineCollection 路径，不只散点 offsets；violin KDE 网格向数据外扩展约 1.5 带宽（平顶判失败）；密度等高线网格扩展约 6%；0/1/阈值上的点加 2–4% 标记边距；最终显示宽度检查栅格；HTML 使用版本化 raster URL 或 no-store 头。


全 panel 数据范围版本，来自 PGv3 六图逐 panel 范围审计：多个坐标轴仍截断真实观测、置信区间
或长尾对照。

- 每个定量 panel 在两个轴上都显示完整数据范围；范围按当前数据计算，不能沿用旧版本硬编码。
- 阈值视图必须配全范围；隐藏零值终点判为失败。
- 审计在数据空间中比较数据极值与排序后的坐标范围，处理倒置/对数轴，逐 panel 记录越界点与相对越界量。
- collection 默认偏移与 legend 代理不计入越界。
- 扩展范围后显式设置刻度，替换落到视图外的自动刻度。

## 1.2.6.7 — 2026-11-25

证据密度与视觉完成度版本，来自 PGv3 六图复核中“技术合格但读起来稀疏、粗糙”的问题。

- 每个分析 panel 至少三层证据（个体观测、分布、带区间估计、参照线、效应量、跨条件对照、
  结构注释），层数写入审计。
- 只有均值柱、无带/无点/无 rug 的单序列判为失败；两柱 panel 必须在同一图中配分布。
- 按算法、规则、环境重复同一编码而不增加分布、对照或机制层，判为失败。
- 视觉完成度：语义色与透明度层级，所有须线与边框使用已注册颜色，禁止默认 #000000，
  禁止大部分空白的 panel。
- 图级节奏：每行承担不同证据角色。
- 增加分层分布、回归带与剂量–响应带的实现配方。

## 1.2.6.6 — 2026-11-24

- 投影面板必须覆盖当前数据全范围，记录零裁切点；PCA/ t-SNE/ UMAP 使用等 x/y 单位长度和方形数据框。
- 折叠证据使用 cartoon/ribbon；非重点链、loop 与上下文使用 20% 透明度（约 80% 可见）。
- 结构渲染前新增 PDB 元素列、guide atom 与 FASTA 完整性门。
- HTML 增加结果主题句、关键数字、逻辑转折和图注推断句的加粗规则。
- HTML 图件使用 600 dpi raster 展示并单独链接 SVG/PDF，浏览器验收改为按图位置截图。

## 1.2.6.4 — 2026-11-24

- 图内显著性统一使用标准星号，精确 q 值保留在图注和源表。
- 连续效应图增加同点 CI 带与代表性星号，避免逐点星号碰撞。
- 图例优先标题下水平横排，状态转移使用短码。
- BioNoether 结构背景改用 ChimeraX `transparency 20`，即约 80% 可见；此前 50%、30%
  和 25% 透明度仍使非重点主链在白色景深下难以辨认。景深从 0.75 起，保留层次而不隐藏骨架。

## 1.2.6.3 — 2026-11-24

- 增加图例—数据硬隔离、短直接标签与多系列回退布局。
- 刻度稀疏时保护 x/y 轴标题，并新增刻度完整性审计。
- 增加动态 panel 标题带、坐标余量和真实比较显著性规则。
- 新增 `legend_data_occlusions`、`axis_tick_completeness`、最终缩放和显著性来源回归。
- BioNoether 结构图回归：非重点 Cartoon 从 72% 透明改为约 50% 透明，并加入白色景深；
  局部视野在命中位点两侧保留 6 个残基，比只看口袋时宽约 20%；同一 panel 禁止全景和
  局部 inset 形成“一大一小”两个分子对象；后续版本将背景可见度进一步提高到约 80%。
- 结构 raster 残基标签从 60 px 改为 52 px，按最终 HTML CSS 宽度复算目标 5–7 pt；
  正文 10 pt 规则不再机械套用于结构 raster。
- 保留上下文的单一结构视图采用主要方向 ≥0.85、次要方向 ≥0.72 的内容占空率门槛，
  并以最大内部空白带 ≤0.14、透明上下文可辨认和关键区域视觉前景作为发布条件。
- 记录作者对 BioNoether 综合图的间距覆盖：完整 panel 边界净空由通用 0.40w 缩至
  0.27–0.29w，默认 0.28w；实现、审计、HTML 说明和 skill 使用同一阈值。
