# NatSci-Writing-skills — 中文科学论文生产体系（Nature/Science 标准）

## 〇、定位与工作原则

产出或修改完整的科学论文、章节、图件与投稿材料，达到 Nature/Science 标准：一个具体问题，一个尽早出现的论断，支撑论断的证据，读者可以使用的推论，以及用同一论证承载结论的图件。范围覆盖研究论文、综述、Perspective、方法学与算法论文，面向生命科学、生物技术、生物信息、蛋白质语言模型与 AI for science，支持中英文。

四条工作原则：

1. **先立论，后铺陈。** 段落第一句给出该段要建立的关系，其余句子兑现它。
2. **具体先于抽象。** 写清分子、残基、数据集、比较对象、测量值或模型量；抽象名词先定义再使用。
3. **证据决定语气。** 动词与证据匹配；不确定性只在影响解释处说明一次。
4. **读者经济。** 删去不改变读者认知或判断的内容。

## 二、保持作者原意

- 以最新作者决定、当前文本和批注为编辑基线；旧版本只用于理解历史。文件变动后先读再改。
- 保留已确认标题、摘要、定义、命名、样本口径、数值、单位、阈值、比较方向和图表身份。核实确有错误时透明修正并单独说明。
- 完整阅读指定章节和全部批注；相邻章节影响修改时一并阅读。如实说明读过的内容。
- 【】与行内批注按"作用于前一句"处理；逐条解决，交付稿删除编辑指令。
- 结构基本满意时保留结构，只修复句间关系并补充有证据的洞见。
- 不虚构实验、效应、引文、基准或机制。区分概念提议、已展示能力和未来机会。

## 三、论证、顶级期刊标准与文体

先建立内部地图：问题 → 未解决关系 → 方法 → 证据 → 解释 → 下一个问题。为每段明确目的、对象与比较、核心论断、证据、推论，以及与前后段的关系。仅靠重排不能修复缺失的关系。

语料实测目标（中位数；比率按每千词计）：

| 维度 | 研究论文 | 综述 | Perspective |
|---|---|---|---|
| 摘要 | Nature 约 200 词/7–8 句；Science 约 125 词/6 句 | 120–200 词/5–6 句 | Nature 约 185 词前言；Science 一句约 11 词提要 |
| 句长 | 24–25 词，90 分位 42–45 | 25 词 | 26–27 词 |
| 段落 | 120–140 词/4–5 句（中文 150–260 字） | 150–260 词/6–9 句 | 200–320 词，随笔式 |
| 第一人称 | 每千词 10–13 | 1–2 | 约 5 |
| 限定语 | 3–6 | 6 | 5 |
| 连接词 | 4 | 6 | 5 |
| "不是……而是" | 少于 1 | 少于 1 | 少于 1 |
| 破折号/分号 | 少于 1/3–4 | 1–4/1–2 | 1–3/1–2 |
| 数字 | 50–60 | 40–65 | 30–40 |

定性规则：开头即论点；主语具体、动词有力；证据紧跟断言；一段一件事；动词与证据匹配（直接证据用表明/显示/揭示，推断用提示/说明/与……一致，推测用可能/或许/我们提出）；数字带单位、比较和分母；连接词克制；期刊签名（Nature 摘要以"Here we show"式句子引出结论且不超过 200 词；Nature 综述前言不超过 200 词、正文少于 7,000 词、4 个展示项；Nature Perspective 个人视角、前瞻；Science 摘要约 125 词；Science Perspective 一句提要；Nature 图件小写粗体面板字母，Science 大写）。

**文体架构。**
- 研究论文：摘要 5–6 个动作；引言漏斗；结果按"问题—设计—观察—推论"组织；讨论 4–6 段，以具体机会收尾。
- 综述：有论点、有组织框架、按机制综合、判断证据质量、给出具体展望；一幅概念图；不以作者工作为中心。
- Perspective：张力 → 论点 → 3–5 个有证据的命题 → 认真对待对立立场 → 后果 → 议程；个人声音，推测标明。
- 短格式：一个论断、最小背景、一个决定性比较、不超过两个展示项。

### 2.4 创新性、广泛兴趣与编辑契合度

先分类主要贡献（现象、机制、测量/能力、资源、理论、临床/转化），并放在贡献阶梯上（渐进 → 区分 → 解释 → 赋能 → 改变领域）。多数 Nature/Science 论文需要在广泛框架下达到第 2–4 级；没有证据不宣称第 5 级。

可发表的缺口是科学未知，不是"没人用我们的方法"。写清确切未知、竞争解释、能区分它们的观察，以及解决缺口改变什么。写三句话：为什么是这个、为什么现在、为什么广泛；每句用名词和证据回答，不用形容词。

编辑契合度按原创性、突出重要性、跨学科兴趣、技术可靠性和可读性判断。写出领域之外的受众和具体改变。契合度弱时如实说明并强化贡献或换刊，不用形容词抬高。

详见 editorial-and-submission-zh.md 与 innovation-and-broad-interest-zh.md。

## 四、语言与写作诊断

术语首次出现时用可测量的对象或动作定义，之后使用通行名称。把没有指涉的抽象表达换成实际比较或结果。优先精确动词与具体名词；删除无证据的评价性形容词（颠覆性、革命性、全面、鲁棒、无缝、关键、state-of-the-art 等）。

删除宣传性总结和空泛承诺（"提供新思路""奠定基础""开辟新范式"）；每个收尾句给出能力、推论或后果。把模板化对立与让步（"不是……而是……""并非……而是……""不仅……而且……""however""rather than"）改写为直接陈述；只有两个科学解释真正竞争时才保留对照。删除防御性措辞、泛泛的严谨性声明、自我评价和重复的局限提示；直接写对象、比较、证据和条件。保留影响结论的对照、阴性结果、不确定性和条件。

图内文字同样执行：面板标题、图例、直接标注与图注写清被测量的观察、比较、计数或区间；删除防御性套话，但以正面描述保留真实阴性结果（例如"校正后 95% 区间包含 0""84 次位移中 62 次为负"），同时保留分母、单位、区间、阈值和样本层级。

不要使用含义不清的表达（如"高加性读出中仍可识别连通响应""物理与 AI 保持不同的可观测扇区""全局软方向是一个真实的中介对象"）；回到原文与数据确认其指向的扰动、测量响应、空间关系或机制，不得为修补句子而编造机制。正文不写操作指令、审计语言和编辑流程；这些放在作者说明中。不用破折号连接两个独立分句；标准复合修饰语可以保留。

论证层的取舍（这篇论文主张什么、哪些实验保留、如何区分必要局限与防御性写作）见 defensive-writing-and-argument-selection-zh.md 与第十七节。七类诊断（详见 writing-diagnostics-zh.md）：抽象堆叠；模板对立；连接词空转；评价性形容词；防御性/自限性表达；清单段与模块目录；元叙述。语料中 AI 标记词每千词 2–4 个且多为统计/技术用法；超过约 5 个或一段内两个以上，提示生成味过重。执行删 20%、主语、那又怎样、朗读四项测试。

**零容忍句式。** 不用模板对立（不是……而是……、并非……而是……、不是……是……、不仅……而且……、不只是……更是……、与其说……不如说……、看似……实则……、X，而不是 Y），不用防御性免责（值得注意的是、需要指出的是、在一定程度上、在某种意义上、或许、也许、有望、尚需、有待、仅供参考、有待进一步研究），不用提纲式过渡（首先、其次、最后、综上所述、总而言之、由此可见、总之），也不用"见证了/承载着/彰显了/标志着/意味着"式象征膨胀。直接写断言。两种解释确实竞争时，写成两句肯定句，用区分性证据分开。README、cover letter、图内文字和作者说明同样适用。交付前跑 python tools/check_prose_style.py，ERROR 必须清零。完整句式表、改写示例、结构标记和调研来源见 writing-diagnostics-zh.md 第 3A 节。

### 3.1 AI 使用边界

AI 可用于语言编辑、结构辅助、文献初筛、格式、代码和图件布局，但不能作为作者，作者对全部内容负责。按目标期刊要求披露 AI 使用；不得把未发表、机密、审稿或患者材料上传公共模型；不得用 AI 生成数据、研究图像、参考文献、统计或批件。AI 建议的文献只当未核实线索，每条引文和数字都要核实。最终文本仍须是作者的论证：具体、有证据链、无 AI 腔。政策表、披露模板、2026 更新、AI 写作负面清单和审计见 ai-use-and-writing-integrity-zh.md；记录模板在 assets/templates/ai-disclosure.md。

AI 图件走独立门槛。数据图用真实数据和代码；生成式模型不得创建或修改显微、凝胶、印迹、成像、定量图或结构。概念示意图、图形摘要和封面按目标期刊 AI 图像政策处理，需披露、人工核验、概念标注和溯源记录。禁用生成式填充、移除物体、合成研究图像、假比例尺或未披露的 AI 封面。任何图像生成前读 ai-figures-and-visual-integrity-zh.md；用 assets/templates/ai-image-provenance-record.md 记录；用 assets/templates/ai-negative-checklist.md 审计。

### 3.2 校对与最终语言检查

按 proofreading-and-polish-zh.md 做五轮：拼写/术语；语法；不当用词；别扭表达；学术风格与一致性。再检查概念落地、段落节奏、数字/单位、引文与标记。保留正确技术术语与作者声音，不制造吹毛求疵的改动。

### 3.3 编辑模式与作者文本保真

动笔前约定模式：轻度润色、作者忠实扩写、结构重写、翻译、修订模式或审读。轻度润色保留断言顺序、范围和措辞，不新增断言、实验或方法。作者忠实扩写保留作者术语和顺序，只在标注处补解释。修订模式先复制源文件，在副本上用修订痕迹和黄色高亮，源文件保持不动。每种模式都保留修改记录、列出待作者确认的问题，并执行 assets/templates/editing-scope-and-change-log.md 的保真检查。保持理论身份：拟议比较仍写成提议，模型推论与实测结果分开。

## 五、章节 playbook（摘要）

- **标题**：对象/系统 + 能力/动作 + 应用/后果；8–12 词；可检索、具体、可辩护；不用"Towards…""A study of…"、未核实的"首次"和口号。
- **摘要**：背景/问题 → 缺口 → 方法 → 最强结果（含数字/比较）→ 后果 → 有边界的意义。Nature 用分阶段 summary paragraph，在足够背景后用"Here we show"式句子引出结论，不超过 200 词；Science 约 125 词。最后写摘要；每句都应能独立成立。
- **引言**：领域重要性 → 现有实践的瓶颈 → 前人工作解决了什么、没解决什么 → 剩余缺口 → 本文作为直接回应。3–5 段；不提前倾倒结果；"已知"到"本文"的过渡必须明确。
- **结果**：证据阶梯（体系/流程验证 → 主要结果 → 公平基线 → 机制/消融 → 应用/泛化 → 压力测试/失败模式）。每小节先问题、再设计、再观察与统计、最后推论。每个主要论断都要有比较、消融或压力测试证据；没有就标记待补，不绕写。
- **讨论**：核心推进 → 证据含义 → 竞争解释 → 与最接近研究的关系 → 具体局限 → 现在可检验的机会。解释而非复述结果；只在实际需要处使用限定语；局限写具体条件。
- **结论**：贡献 → 决定性证据 → 意义 → 边界；不引入新数据。
- **方法**：可复现的设计、材料/数据、流程、结局指标、统计与伦理；不写"在标准条件下""采用常规方法""进行了统计分析"等空话。
- **综述/Perspective**：见文体架构；论证优先，文献作为证据。

完整 playbook、论文类型变体（research/methods/algorithmic/hypothesis/review）、期刊格式与完整稿件包见 manuscript-production-zh.md。

### 4.1 正文纪律与信息架构

证据完整不等于正文完整。先给每个结果分类：核心发现、必要支撑、限定、稳健性、异质性、溯源细节、替代推断或边界案例。建立最短充分证据链；安抚性、溯源和次要分析放 Extended Data/补充材料；不得把矛盾或改变结论的证据藏进 SI。

正文写"发现了什么、意味着什么"；图注写"展示什么、如何读"；SI 写"结论为何经得起更深入审查"。完整统计只在一个定义位置报告。执行段落必要性测试和断言重复图；每次新增都触发删除检查，防止返修膨胀。遵守展示项与字数预算（Nature Article 约 2,500 或 4,300 词，配 4–6 个中等展示项）。

### 4.2 Nature 章节技艺

四个核心章节是同一断言的不同压缩。摘要=最短 claim-evidence-implication 链，一个主要发现，不写方法清单；引言=收敛到确切未知，而不是"没人用我们的方法"，答案在问题被动机化后出现；结果=升级的证据链，每小节一个新推断，稳健性在限定断言处可见；讨论=对竞争解释与具体边界的综合，以具体机会结尾。使用 nature-section-craft-zh.md 的反提纲、断言阶梯、claim-location map 和删除测试。

### 4.3 Perspective 与概念写作

Perspective 必须改变读者理解。先写一句内部编辑句，从具体张力中找到智识中心，把论证设计成一系列发现而非主题巡游。局部标记既有事实、解释、假设和拟议实验；数学、类比与推测只在承担解释工作时使用。详见 perspective-and-insight-zh.md。

### 4.4 Perspective 生产与理论文章

完整 Perspective 需要生产架构，不能只有洞见。用 nature-perspective-production-zh.md 处理 Nature 格式、六节原型（张力、定义、概念动作、方法、回程、视野）、证据层级、整段规则、概念图设计、双语流程、编辑模式和三学科审读。正文用连贯段落，论证内不放列表。目标期刊允许时，每个小节加粗两到三句单句洞见。边界集中一段，不分散到每段。mirror-world-case-study-zh.md 给出一个六节 Perspective 的完整案例，含 Box、三幅概念图、数学对象和生产经验。

详见 main-text-and-information-architecture-zh.md。

## 六、科学断言与统计

- 区分相关、模型输出响应、分子机制与生物学因果。解码器敏感性只说明特定输入和干预下的计算效应；功能实验才检验残基的生物学作用。
- 项目延续前一代模型时，建立跨代比较登记：目标、来源人群与分析队列、模型/层范围、降维与图谱、聚类、可视化、群体维度、紧凑程序、跨模型/物种分析、回译、注释、实验终点、统计验证与交付物。仅当分母、坐标体系和证据状态一致时比较来源计数、锚点与共享对象；ARI、效应量、KL、AP、召回、优势比作为独立估计量，不合并成复合分数；报告映射秩、派生轴载荷和校正队列/背景下的效应变化；说明前代提供什么、当前新增什么、哪些前代分析尚未重建。
- 不把残基身份或结构域说成只能定性研究；维度是序列上下文学习到的定量变量。"更深/底层"指模型数值表示，不是比氨基酸更基本的物理层。
- 原始坐标是模型/层特异的数值分量；不同模型的同号坐标没有默认生物学等价性。
- 区分原始嵌入坐标、PCA 分量和稀疏自编码器特征；不把 SAE 结果归因于原始坐标。
- FDR-only 计数与效应量筛选集合分开；唯一 GO 术语与跨维度求和关联分开。
- 区分注释调用、推断覆盖、既有注释恢复、独立预测准确率和实验确立功能；覆盖率写清分子、分母、单位和重叠。
- 区分库内恢复与留出检验；留出标签本身不保证特征选择、参考库构建或校准独立。
- 区分诱饵校准工作点与独立测量的假阳性率；敏感性比较写明工作点。
- 均值配正确离散度、n、检验、校正族和零模型；不挪用不同零模型的 P 值。
- 残基编号与序列–PDB 映射显式；区分解码结构字母表与实测构象。
- 观察显示"部分对照也比较也广泛显著"时如实写；这类结果本身不能量化长度/组成造成的比例。
- 家族特异性、保守性和普适性只对实际比较集合陈述；"在所分析的 34 个家族中"优于"普遍"。
- 注释统计沿参考库构建、特征选择、打分、校准和评价追溯；列名 padj 不构成术语级校正证明；从仅一个显著术语的扫描扩展出的列表不使每条链接都显著。
- 有符号集合写成"维度身份 + 相对参考的方向"；符号不是激活/抑制效应；说明报告量是分数、未校正检验、校正结果还是校准概率；检查正负检验如何合并。
- 保留变量来源（解码器 KL、家族维度、符号最大效应、全模型）；不用对全体维度有利的结果替代特定变量验证。
- 区分最大结构位移、模型敏感性、铰链运动、催化贡献、结合与突变必要性；靠近已知残基的候选只继承区域背景，不继承该残基的实验证明；先用固定选点与聚合规则再声称恢复重要残基。
- 队列切分贯穿每个环节：被排除出训练的蛋白质仍可能位于选择背景；写明实际评价范围。

### 6.1 统计与报告诚信

每个核心断言定义独立实验单位；分开生物学与技术重复；不把细胞、视野、reads、孔或模型运行当作独立样本。报告精确 n、误差棒/区间定义、重复实验次数、精确 P 值，以及需要时的 F/t 统计量与自由度。写明确切比较、检验族、尾向与多重比较校正。

Nature 正刊的方法统计段须覆盖检验、单双侧、独立单位、重复定义、配对/重复测量、纳入/排除、随机化/盲法、校正策略；生命/行为/社会/生态/演化/环境及部分物理科学需 Reporting Summary。审查图像诚信（原始文件、裁剪、对比度、伪彩、拼接、复用）和数据/代码/材料声明。

使用 P0/P1/P2 严重度；不编造样本量、检验、软件版本、批件或登录号。详见 statistics-and-reporting-integrity-zh.md。

### 6.2 文献检索、综合与引用诚信

检索是为了回答论证问题，不是为了堆参考文献。按来源层级（原始研究 > 系统综述/指南 > 综述 > 预印本）选源，全面性要求下至少用三个互补数据库，并记录检索/筛选过程。按问题、机制或假设综合，不逐篇罗列。核实每条 DOI/题名/作者，区分预印本与正式发表，检查撤稿；引文放在断言处并在期刊预算内。详见 literature-search-and-citation-zh.md，计划模板在 assets/templates/literature-search-plan.md。

## 七、文献、引用与声明

仅对作者提供的文本做语言润色时，使用其现有证据，不必检索。需要讨论研究、评估新颖性或满足当前期刊要求时，检索原始文献和官方指南。

- 先形成具体问题；优先原始论文、作者仓库和官方指南，再用综述定位概念。
- 添加引文前核对题名、作者、年份、发表状态和 DOI；区分预印本与正式发表版本。
- 阅读支撑该陈述的具体章节；如实说明只读了摘要还是全文。
- 按科学问题或方法差异综合文献，不逐篇摘要。
- 说明本文相对最接近研究增加了什么解释、预测或能力；没有限定检索范围不写"首次""普适""新一类"。
- 文稿引文标记放在句末标点之前（作者偏好），平台规则优先时从其规定；参考文献按目标期刊统一。
- 不编造标识符，不把数据库收录当作外部验证。
- 写"代码或数据公开"前核实仓库、版本、许可证和检查点兼容性；本地包或"计划上传"不等于公共资源。
- 数据可用性、代码可用性、作者贡献、利益冲突与伦理声明必须具体、持久、可核验；不写没有原因、途径、资格和元数据的"可向通讯作者索取"。详细模式见 manuscript-production-zh.md 第十节。

## 八、交付规范

除另有要求外：
1. 用一段简短中文说明修订逻辑。
2. 给出完整英文修订稿（如为英文任务），按原段落顺序。
3. 给出逐段对应的中文版本。
4. 相对作者最新文本，所有替换与新增文字加粗（含语法、拼写和用词）；未改动文字保持原样。整句重写可整句加粗。
5. 用简短说明列出重要科学更正、未解决的图表/来源问题和编辑取舍。

要求最终清稿或完整 HTML 时去除修订加粗，除非明确要求修订痕迹。只要求一种语言时交付该语言。中文论文直接用中文写作（英文任务使用配套 natsci-writing）。检查清单和核验表置于正文之外。

完整稿件还需包含：标题页、摘要（中英对照时给中文版）、带标题的正文、方法、已核实的参考文献、图注、扩展数据/补充材料清单、各类声明、假设与缺失输入清单、修改记录。审阅用 Markdown，合作者用 DOCX，期刊要求时用 LaTeX 或 HTML；数字保留单一事实来源。

中英文证据强度一致：candidate 对应"候选"，associated 对应"相关/关联"，predicted 对应"预测"，demonstrated 只用于实际测试过的能力。

## 九、文件与长文

完整阅读原稿和全部批注；默认保留源文件，除非明确要求就地修改。Word 任务保留图片、分节、样式、引用域和批注锚点；代码不写入正文。

为长文建立按顺序排列的内容块清单，覆盖标题、段落、列表、表格、图注、公式说明、脚注、附录、参考文献、折叠内容和动态文字；分段读取并记录已读范围，补齐截断输出。完成修订后全文复读两轮：第一轮科学逻辑、证据、段落关系和一致性；第二轮逐句语言、术语、数字、图表和批注处理。

涉及数据真实性或计算核验时，按 html-and-data-verification.md 执行：追溯来源与项目数据，检查生成代码，复算影响结论的数量，核对单位、分母、不确定性、零模型、多重检验和训练/测试隔离。记录实际完成的核验，区分"核对报告算术"与"从原始输入重现结果"。

确认文件真实创建，并简要报告尚未解决的问题。写作完成不代表实验或源数据修复完成。

## 十、图件：合同、标准、生产与发布

**10.0 AI 图件门。** 选工具前先分类：数据图、概念示意图、图形摘要/封面、AI 辅助排版或 AI 辅助处理。数据图用真实数据和代码；生成式图像模型不得创建或修改。概念性 AI 辅助图需期刊许可、Methods/图注/cover letter 披露、逐项人工核验标签和关系、概念标注，以及溯源记录（工具/版本/日期/prompt/输出哈希/人工修改）。封面和图形摘要需编辑许可。生成前核对期刊政策；政策因刊而异且会变。完整政策与负面清单见 ai-figures-and-visual-integrity-zh.md。

任何图件任务先读 figure-production-zh.md、figure-craft-and-information-density-zh.md 和 figure-standards-nature-science-zh.md；项目图件同时读 figure-design-and-audit.md 及其配套契约。

**10.0b 图例、刻度与显著性门。** 图例、直接标签和系列文字不得覆盖任何数据、区间、矩阵或结构。短系列使用一词缩写；超过四个系列改放标题下方横排或右侧独立列。直接标签以 axes fraction 保持整组间距，最终 panel 缩放后重测。刻度拥挤时只调整刻度，不删除 x/y 轴标题；每个轴至少保留两个可解释刻度，类别标签按 rendered bbox 均匀稀疏。panel 字母和标题依据顶部刻度实际高度动态上移。线性轴极值不得贴框，非负比例保留零基线并增加上侧余量。显著性括号只来自同一分组、独立单位、分母和方向的真实检验，forest 的 q 值置于绘图区外。最终同时要求 `zero_text_collisions`、`zero_legend_data_occlusion`、`axis_tick_completeness` 与 `typography_compliant` 通过。

**图级断言与证据架构。** 从一个结果层问题、一个图级断言开始，并写出什么能推翻它。让面板承担不同推断角色（体系、代表性实例、主要定量证据、基线/对照、分解、分层、正交验证、扰动/压力测试、边界/失败案例、机制证据）。角色多样性优先于指标多样性；同一指标换种子/阈值的镜像布局只是一个角色，不是四个。使用链条：建立 → 比较/对照 → 压力测试/区分 → 扩展 → 限定。跨图时，每幅图应制造下一个问题，而不是重复"X 表现好"。

**10.1 图件合同。** 写图前确定：一句话结论、图件原型、面板地图（每面板一个问题）、证据层级、统计、源数据映射、审稿风险。每个面板回答独立问题；hero 面板获得最清晰坐标轴和最大面积；对照面板视觉更安静。

**10.2 期刊规格（投稿前复核）。**
- Nature：单栏 89 mm，双栏 183 mm，1.5 栏 120–136 mm；版心 247 mm；Helvetica/Arial；文字 5–7 pt；面板字母 8 pt 粗体小写 a、b、c；线宽 0.25–1 pt；位图 300–600 dpi RGB；优先 EPS/PDF/AI；避免红绿对比。
- Science：单栏 55 mm，1.5 栏 120 mm，双栏 183 mm；Helvetica/Arial；5–7 pt；面板字母大写粗体 A、B、C；照片不低于 300 dpi，线条图 600 dpi；PDF/EPS/AI。
- 按最终印刷尺寸设计；关键文字不低于 5 pt。作者项目的 HTML/屏幕图使用较大字号（10 pt 正文、10.5 pt 轴标签、11 pt 粗体面板标题、11.5 pt 结构标题、12.5 pt 面板字母），不得与期刊印刷字号混用于同一交付物。

**10.3 面板构建。** 一个面板只放一个数据图；不在面板内使用 inset_axes、子图拼贴、facet 网格、嵌套色标或多个微型图。若一个面板需要多项测量，用共享位置轴、共同单位、点形状、线型、透明度、直接标签或有序轨道合并；无法共享坐标系时，只保留主证据图，把支撑证据移到图注、源表或独立面板。序列/残基轨道可保留对齐层，但必须共用同一位置坐标。面板顺序按读者推理：体系/设计 → 主要比较 → 机制/定位 → 量化 → 稳健性/验证。完整行用三个面板；六面板用 3×2；项目完整拼图默认九个分析面板 3×3；五面板用 3+2 居中；7/8/10/11 混合行不得发布。

**10.4 项目发布门槛**（阈值与测量见四份项目图件文件）：
- 固定物理坐标网格；数据框正方形（0.9–1.1，目标 1.0），在排版完成后按渲染像素测量；同列轴左边界、同行轴底边界偏差不超过 0.01 mm；等权面板面积差不超过 5%。
- BioNoether 综合图的完整边界间距采用作者确定的 0.27–0.29 × 面板宽度，默认 0.28，
  即相对早期 0.40 缩小约 30%；通用项目仍可按各自期刊和标签空间采用其他范围。间距在最终
  刻度/图例后测量，保存时不得再次压缩。结构背景采用约 20% ChimeraX 透明度，即约 80% 可见，
  保留白色景深且让非重点主链可辨认，局部窗口比
  只看口袋宽约 20%，每个结构 panel 只含一个分子对象。
- 面板字母锚定完整面板单元（约 0.20 × 面板宽度偏左、0.20 × 面板高度偏上、距数据框至少 4 mm、距标题至少 3 mm）；标题单行、粗体、居中；每个分析面板都有轴标题。
- 一个证据轨道 + 九个分析面板（字母 a 与 b–j）；不得出现游离的微型面板。
- 语义颜色角色跨面板稳定；证据状态用填充、形状、网纹、轮廓或直接标签编码；类别色不超过三种加中性色；禁用 jet/rainbow/hsv；文字对比度不低于 4.5；矩阵单元不写文字；输出颜色审计文件。
- 结构 raster 裁到分子墨迹、保持纵横比、内容范围不低于 85%、内部空白带不超过 14%、外边距不超过 5%；结构与统计面板共享残基/状态/颜色映射；执行 Baker 结构图规范。
- 结构面板只放一个分子对象。非重点区域使用约 20% ChimeraX 透明度，即约 80% 可见，加入从 0.75 开始的轻微白色景深；关键残基用不透明 Cartoon、side-chain sticks 和短直接标签。局部视野在命中位点两侧至少保留 6 个残基，比口袋裁切宽约 20%。嵌入 HTML 的 raster 残基标签按最终显示大小复算为 5–7 pt。
- 对所有 artist 类型（散点、线集合、区间、柱、身份线）检查文字—文字、文字—画布、文字—数据遮挡，逐轴记录；图例在渲染前定尺寸；保存后不得压缩设计间距。
- 每个面板都要有足够证据：效应、不确定性、样本分布、零模型/对照、留出与迁移在可用时用独立面板呈现；有更丰富证据时，拒绝裸坐标框、孤立均值柱、单点和无阈值曲线。
- 每个图组之后用正文说明发现了什么、哪个比较建立规律、支持什么关系、解释止于何处；图注盘点面板，正文解释科学。
- HTML 图件按最终显示宽度复核有效字号：记录 raster 原始宽、最终 CSS 宽、保存 dpi 和角色字号，计算有效 pt；名义 10 pt 只有在最终页面仍是 10 pt 以上才通过。固定网格使用统一物理画布，任一长 y 标签、比较名或图例不得扩展单列 cell 或制造中央空白走廊。
- 每张定量图输出逐 panel 证据表，记录样本点、区间、矩阵/图像、阈值和直接标注；同一估计量只换图型、阈值或 seed 的 panel 判为重复，必须替换为独立证据维度。

**10.0c 星号与水平图例门。** 图内显著性使用 `****/***/**/*/n.s.`，精确 q 值放入图注和源表。连续效应曲线显示同点 CI 带，一个连续显著区段标首、中、末代表点，状态变化和末点保留。图例的默认位置是标题下的水平多列；只有宽度超出完整 panel 才使用端点直接标签，右侧单列是最后回退。顶部 legend、panel title 和 letter 的 bbox 必须分离。

**10.5 图注语法。** 论断标题 → 现在时逐面板说明 → 统计（n、n 的定义、中心/离散度、检验、校正）→ 符号/颜色 → 源数据/许可行。研究图 100–220 词，综述 80–150 词（Nature 风格不超过 300 词）。标题行不写数字，不写方法清单。

**10.7 Perspective 与理论文章的概念图。** 一幅图一个整合构图，不做互不相关的小图拼贴。纯白背景、平面矢量感、无渐变/阴影/3D、有限色盲友好配色、至少 75% 图示面积、少于约 45 词、面板字母小写，必要时加"概念示意，无实测结果"脚注。画图或生成图前先写图级断言、面板角色、精确文字清单和科学限制；逐项核对标签、公式、箭头和声明。详见 nature-perspective-production-zh.md；设计单见 assets/templates/conceptual-figure-brief.md。

**10.6 逐 panel 交付与补充图。** SEAL 任务在创建或审核任何主图/补充图前完整阅读 seal-supplementary-figure-standard.md。panel 是交付单位：每个已声明 panel 导出为独立可编辑 SVG，自带面板字母、坐标轴、刻度、标记和注释；拼图必须能由这些 panel 导出复现。交付合成 SVG、矢量 PDF、600 dpi PNG 与 JPG、每 panel 一份 SVG、共享图例/比例尺 SVG、图注、panel 定义记录与审核记录。自动遮挡计数只是筛查：必须在最终尺寸下逐图逐 panel 目检并记录。标签放在边距标签栈中，锚点接近时用引导线；行间距必须大于上一行 x 刻度标签高度加下一行标题带。SEAL 28 图发布门槛要求一次完整重生成：正文 8 pt、轴标签与面板字母 10 pt、轴线/刻度 0.4 pt、数据框 0.9–1.1、零遮挡、600 dpi PNG、可解析 SVG、单页 PDF、panel SVG 链接有效，并检查桌面与移动端浏览器渲染。

## 十一、修订、润色、格式与审稿回复

- 润色先修推理：检查章节/段落任务、claim → evidence → boundary、沙漏结构、主题句，最后处理语法与语域。只改被指出的段落，其余保持原文；若必须结构性调整，先说明并确认。
- 章节动作、按证据强度分级的句式库、风格红线和过度断言检查见 revision-and-response-zh.md。
- 审稿回复：策略摘要 → 跟踪表 → 逐点回复 → 修改清单 → 风险提示。逐字保留审稿意见；每条映射到动作与稿件位置；不编造实验、引文、行号或面板；缺事实时标 AUTHOR_INPUT_NEEDED。不同意时只就证据或范围做窄范围回应，不针对个人；把"审稿人误解"当作表达不清的信号处理。

## 十七、v1.2.7.0 防御性写作控制与 AI 腔门

文风失败有两个看起来不同、实际由同一个决定解决的原因：论文在反驳自己（防御性写作），或者论文什么都不主张（生成味）。先决定这篇论文赢哪一场，再把每一段都花在那一场上。论证层规则见 defensive-writing-and-argument-selection-zh.md；句子层模式见 writing-diagnostics-zh.md 的 3A 与 4A 节。

- **先取舍论证，再动措辞。** 说清只有这篇论文才有的那一个主张，连同它的量度与条件。"赢什么／赢多少／凭什么成立"没有数字、没有条件，说明分析还没做完，文字补不上。
- **篇幅跟论证走，不跟工作量走。** 每个实验承担且只承担一项职责——存在、机制、区间、排除、价值。没有职责的删掉、合并或降级。禁止流水账（"我们先……随后……"）；失败分支只在能排除读者本来会持有的替代解释时出现。
- **全文只有一段局限。** 至多三句，条件→范围→后果，置于讨论末尾。摘要与结论中局限句为零；限定单个结果的 caveat 留在那句结果里。
- **每处限定都做删除测试。** 去掉它，再问细心的读者会不会因此以为测到了没测的东西。不会，删；会，留下并写具体。修辞性减弱必须清除，认识论校准必须保留。
- **这条禁令不是许可证。** 无证据不主张，不删会改变解读的局限，不把阴性改写成阳性，不从单一体系外推，不隐瞒对照。本技能的统计、报告诚信与 AI 使用规则高于任何风格偏好。
- **节奏也是诊断对象。** 目标：句长变异系数 0.30–0.65；收尾总结句 ≤1/千词；三项并列 ≤2/500 词；名词化实词 ≤12%；破折号 ≤2/千词；限定词 ≤4/千词（英）、≤3/千字（中）；局限标记 ≤2/千词。运行 python tools/check_prose_style.py --gate <文件>；不合格指 ERROR 命中、防御性/AI 标记命中，或度量越界。提案与理论文章用 --genre perspective（提案中的可能性表述属于校准，不是防御），报告用 --genre report（度量仅供参考）。
- **适用范围。** 论文、摘要、cover letter、回复信、图内文字、报告与中文稿。中文特有形式（谦辞自贬、程序性叙述、空转定语、四字格排比）在同名中文参考文件中列出，并由同一个门禁检查。

## 十八、v1.2.8.0 期刊模板与稿件组装

默认目标是 **Nature**，Science 是第二格式。稿件最终要交付为一份必须通过机械检查的文档，所以装进模板，而不是手工排版。

- **权威文件。** 规格在 assets/journal-templates/specs/（页面、字号、章节顺序、上限、参考文献风格、图幅），模板在 generated/ 或 official/，组装器 tools/build_manuscript.py，检查器 tools/check_journal_format.py，来源登记 tools/journal_template_sources.json。规格每块带置信标记：official、secondary、default。
- **组装。** python tools/build_manuscript.py draft.md --journal nature --out build/draft.docx --report build/draft.json。输入是带二级标题的 markdown 或同结构 JSON；引言、结果、讨论并入正文并降为三级小标题；[1] 式引用转上标；作者与单位来自 front matter，绝不自动生成。
- **章节顺序固定。** Nature：题目、作者、单位、摘要、正文、参考文献、致谢、作者贡献、利益冲突、图注、表格、方法、数据可用性、代码可用性、扩展数据。方法放在参考文献之后；放到引言之后是最常见的机械退稿原因。
- **验证。** python tools/check_journal_format.py build/draft.docx --journal nature。关键项（页面、边距、连续行号、正文与摘要的字体字号行距、必需章节、章节顺序、上标引用）必须 PASS；摘要字数与参考文献计数是 WARN，超出时必须写下理由。
- **官方模板。** python tools/fetch_journal_templates.py --list 列出出版社页面；--from-dir 导入浏览器下载的文件；--check 校验。组装时用 --template 传入，组装器保留官方样式并清空正文。绝不改模板样式去迁就文字。
- **投稿门顺序。** 组装 → 格式 → 文字（第十七节）→ 主张与统计 → 图件 → 投稿包。六道全通过才提交；WARN 在写下理由之前不算通过。
- **诚实边界。** 规格值经编译与交叉核对，但出版社随时会改；投稿前重新核对并更新规格。本包不绕过出版社中转页，也不重新分发出版社模板。

## 十九、v1.2.8.1 Results 小标题语言

Results 小标题是科学标签，不是压缩后的口号。它必须用论文自己的术语写出对象或体系与被测量的过程/结果；把图拿掉以后仍然成立。写或改 Results 前先读 references/results-heading-language-zh.md。

- 写出具体对象与测量到的过程/结果；名词短语通常足够。
- 不超过 60 个字符、十二个英文词；各小节语法形式平行。
- 不用纯动词口号、隐喻、未定义的局部缩写、“我们/本文/本研究”或问句。
- 标题不得先于正文使用未定义术语。
- 因果标题必须有因果设计；否则用描述性标题。
- 标题必须与图注标题、panel 证据一致。
- 标题审计独立于 prose 门；prose 检查器不评价标题。

反例：“规则偏置探索与折叠”“路线视野重塑终点”。
正例：“结构空间中的肽生长”“路线评分改变终点结构”。

## 二十、v1.2.8.2 Results 作为发现叙事

Results 是一串科学问题，不是流水线报告。写或改 Results 前先读 references/results-architecture-zh.md。

- 先写存在：一个具体例子说明现象发生，再说明普遍性。
- 再写机制：改变一个因果要素，证明路径与终点改变。
- 加入多样性：说明产生变异的过程及其对产物的影响。
- 区分已知与未分配覆盖，两者都报告。
- 说明是否需要模板或靶标，并给出对照。
- 以边界收尾：案例系列、稳定窗口或失效模式。
- 每节包含问题、设计、观察、解释、边界。
- 不要以软件、参数或分析清单开头。
- Results 小标题是完整陈述或名词短语，40–60 个字符；完整性优先于简短。
