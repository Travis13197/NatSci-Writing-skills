# AI 使用负面清单

## 作者身份与披露

- [ ] AI 未列为作者、贡献者或通讯联系人。
- [ ] AI 使用在要求位置披露，写清工具、任务、章节和监督。
- [ ] 稿件、图注、cover letter 和投稿系统的披露一致。
- [ ] 实际用了 AI 就不声称"未使用"。
- [ ] 不用 AI 改写规避检测或隐藏辅助。

## 文字与引用

- [ ] 无编造文献、DOI、URL、ISBN、登录号或批件。
- [ ] 每条引文支持其句子，并对照来源核实。
- [ ] 无编造方法、参数、软件版本、样本量或统计。
- [ ] 无文本重复、自我抄袭、重复投稿或切香肠。
- [ ] 无论文工厂模式、扭曲短语或买卖署名。
- [ ] 无 AI 生成审稿意见或编辑决定。
- [ ] 无 AI 生成、夸大论文的 cover letter 或意义声明。
- [ ] 稿件体现实质人工分析、解释和核验。

## 数据与图像

- [ ] 无 AI 生成或修改的研究图像、显微、凝胶、印迹、定量图或结构。
- [ ] 研究图像中无生成式填充、移除物体或合成数据。
- [ ] 每幅 AI 辅助图有溯源记录。
- [ ] 数据图由真实数据和代码生成。
- [ ] AI 概念图标明概念性并披露。
- [ ] 无假比例尺、误差棒、显著性标记或成功率。
- [ ] prompt 和输出不含机密、患者或受限第三方材料。
- [ ] prompt/输出不含版权角色、标识、照片或可识别人物。
- [ ] 工具条款和出版社许可允许生成内容。

## 审稿与边界

- [ ] 审稿人/编辑未把稿件或数据上传公共 AI 工具。
- [ ] 期刊政策 URL 与日期已记录。
- [ ] 版权、许可和工具条款已核对。
- [ ] 不把 AI 检测当作人工审读的替代。
- [ ] 人类作者能辩护每一句、每个数字和每幅图。
